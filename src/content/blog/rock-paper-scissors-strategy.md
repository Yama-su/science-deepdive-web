## 1. 素朴な疑問

じゃんけんは、グー・チョキ・パーのどれを出すかを瞬時に決める、単純な運のゲームに見えます。しかし数学的に見て、相手に「絶対に負けない」、あるいは「一番安全な」戦略は存在するのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「多くの人はグーを出しやすいから、グーに勝つパーを出すのが得策」説</li>
    <li><strong>直感2：</strong>「相手の癖を読み切れば、必ず勝てるようになる」説</li>
    <li><strong>直感3：</strong>「じゃんけんは完全にランダムな運のゲームで、戦略というもの自体が存在しない」説</li>
  </ul>
</div>

実際には、「完全に読み合いを尽くした、合理的で予測不能な相手」に対しては、数学的に証明された、唯一の「最も安全な」戦略が存在します。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    もしあなたがいつも同じ手や、偏った出し方をしていると、相手にそのクセを見抜かれて負け続けてしまいます。
    逆に、グー・チョキ・パーをまったく同じ確率（3分の1ずつ）で、完全にランダムに出せば、
    相手はあなたの次の手をまったく予測できなくなり、どんな戦略を使ってもあなたに勝ち越すことができなくなります。
  </p>
</div>

## 4. わかりやすく厳密な答え

このような「相手にとって、こちらの手が一切読めない」状態を、ゲーム理論では「ナッシュ均衡」と呼びます。

<div class="math-proof-box">
<div class="proof-header">じゃんけんのナッシュ均衡</div>
<div class="proof-body">

自分がグー・パー・チョキを、それぞれ確率 $p_r, p_p, p_s$（$p_r+p_p+p_s=1$）で出すとする。

相手が特定の手（例えばグー）だけを固定して出し続けたときの、相手の期待利得（勝ちを+1、負けを-1、あいこを0とする）は、

$$\text{相手がグーを出したときの利得} = p_s - p_p$$

（グーはチョキに勝ち、パーに負けるため）

自分の戦略が「相手に読まれても搾取されない」ためには、相手がどの手を固定して出しても、
相手の期待利得が0以下（自分が不利にならない）でなければならない。
対称性から、これは3つの利得がすべて等しく0になる場合にのみ成り立ち、解くと、

$$p_r = p_p = p_s = \frac{1}{3}$$

</div>
</div>

つまり、グー・チョキ・パーを完全に均等な確率（3分の1ずつ）でランダムに出すことが、唯一「相手にどう出し抜こうとされても、期待値の上では絶対に負け越さない」安全な戦略です。ただし注意が必要なのは、この戦略は「負けないための盾」であって、「勝つための矛」ではないという点です。均等な戦略を取ると、相手がどんな手の出し方をしても、あなたの勝率・負け率・あいこの率はすべて正確に3分の1ずつになります。相手の癖を読んで積極的に勝ちを狙う戦略とは、目的が異なります。

## 5. 数値シミュレーション

偏った戦略の選手と、均等な1/3ずつの戦略の選手が、それぞれ「相手の傾向を見切って対策してくる相手」と対戦したときの、相手の勝率をシミュレーションしました。

![偏った戦略と均等な戦略、それぞれに対する相手の勝率を比較した棒グラフ](/assets/simulations/rps_nash_equilibrium.png)
*図1: グーを60%出す偏ったプレイヤーは相手に読まれて59.7%も負け越すが、均等な1/3戦略なら相手にどう対策されても勝率はきっちり33%に抑えられる*

グラフの左側（赤）は、グーを60%の確率で出す偏った戦略の選手が、常にパー（グーに勝つ手）を出し続ける相手と対戦した結果です。相手はこの偏りを完全に見切っているため、約60%という高い勝率で勝ち越してしまいます。一方グラフの右側（青）は、均等に1/3ずつランダムに手を出す選手が、まったく同じ「常にパー」の相手と対戦した結果です。相手がどんな固定戦略を取ろうとも、勝率はぴったり33%（緑の破線が示す理論値の1/3）に抑えられており、搾取されていないことがわかります。

```python
import numpy as np

rng = np.random.default_rng(42)
n_games = 20000

biased_player = rng.choice([0, 1, 2], size=n_games, p=[0.6, 0.2, 0.2])  # 0=グー,1=パー,2=チョキ
uniform_player = rng.choice([0, 1, 2], size=n_games, p=[1/3, 1/3, 1/3])
exploiter = np.full(n_games, 1)  # 常にパー
# exploiterの勝率は、biased_playerに対しては約60%、uniform_playerに対しては約33%
```

## 8. さらなる疑問

**Q. 相手が完全にランダムではなく、何らかのクセを持っている場合、どう対応すべきですか？**
相手の手の出現頻度に偏りがあることが統計的にわかっている場合、その偏りを突く形で自分の戦略を調整する（相手が最も出す手に勝つ手を、少し多めに出す）ことで、理論上33%を上回る勝率を狙うことができます。ただし、これは「相手が均等ランダムには程遠い」という前提が成り立つ場合に限られ、もし相手も同時に読み合いをしてくる場合には、双方が均等戦略に収束していく傾向があります。

**Q. じゃんけんの実際の大会や統計データでは、本当に均等な1/3ずつになっているのですか？**
実際の人間どうしのじゃんけんの統計を取ると、初心者は最初にグーを出しやすい、負けた直後は勝った手を出しやすいなど、いくつかの心理的な偏りが報告されています。これは「理論上の最適戦略（均等ランダム）」と「実際の人間の行動」が必ずしも一致しないことを示す興味深い例であり、行動経済学の研究対象にもなっています。

**Q. じゃんけん以外にも、同じような「均等な確率が最適」となるゲームはありますか？**
はい。サッカーのPK戦で、キッカーがどちらに蹴るかを読まれないようにする戦略や、テニスのサーブのコース選択など、「相手に自分の行動パターンを読まれたくない」という状況全般に、同じナッシュ均衡の考え方が応用されています。実際のプロスポーツの統計データを分析し、選手の行動がどれだけ理論上の最適な混合戦略に近いかを検証する研究も存在します。

## 9. 数式の完全な導出

4章では、対称性の議論から $p_r=p_p=p_s=1/3$ を導きましたが、ここではその根拠となる連立方程式を、一切の飛躍なく丁寧に解きます。

### ステップ1: 相手が各手を固定したときの期待利得を、すべて書き出す

自分の戦略を $(p_r, p_p, p_s)$ とします。相手が「グー」を固定して出したときの、相手から見た期待利得 $U_r$ は、自分がチョキを出せば相手（グー）の勝ち（+1）、自分がパーを出せば相手の負け（-1）、自分がグーを出せばあいこ（0）なので、

$$U_r = p_s \times (+1) + p_p \times (-1) + p_r \times 0 = p_s - p_p$$

同様に、相手が「パー」を固定したときの期待利得 $U_p$、「チョキ」を固定したときの期待利得 $U_s$ を求めると、

$$U_p = p_r - p_s, \qquad U_s = p_p - p_r$$

### ステップ2: 「搾取されない」条件を数式にする

自分の戦略が搾取されないためには、相手がどの手を固定しても、相手の期待利得が0を超えてはいけません（0を超えれば、相手はその手を選び続けることで有利になれてしまいます）。

$$U_r \le 0, \qquad U_p \le 0, \qquad U_s \le 0$$

### ステップ3: 3つの不等式を足し合わせる

$$U_r + U_p + U_s = (p_s-p_p) + (p_r-p_s) + (p_p-p_r) = 0$$

これは常に恒等的にゼロになります（各項が打ち消し合うため）。3つの数の合計が常にゼロで、かつステップ2の条件からすべてが0以下でなければならないということは、**3つとも同時に0でなければならない**ことを意味します（もしどれか1つでも負であれば、合計をゼロにするために、他のどれかが正でなければならず、ステップ2の条件に反してしまいます）。

### ステップ4: 連立方程式を解く

したがって、

$$p_s - p_p = 0, \qquad p_r - p_s = 0, \qquad p_p - p_r = 0$$

という3つの式が同時に成り立つ必要があります。これらは互いに独立ではなく（1つ目と2つ目を足すと3つ目が導けます）、本質的には「$p_r=p_p=p_s$」という1つの関係を表しています。

### ステップ5: 確率の合計が1であるという制約を使う

$p_r=p_p=p_s=x$ とおくと、確率の合計は必ず1になるという制約から、

$$p_r+p_p+p_s = 3x = 1 \implies x = \frac{1}{3}$$

### 結論

$$p_r = p_p = p_s = \frac{1}{3}$$

以上のように、「相手がどんな固定戦略を取っても、相手を有利にしない」という条件だけから、連立方程式を機械的に解くことで、グー・パー・チョキを均等な確率で出す戦略が、唯一の解として導かれました。この戦略は、対称性からの直感的な予想と一致するだけでなく、不等式と連立方程式を使った厳密な手続きによっても、確かに裏付けられているのです。
