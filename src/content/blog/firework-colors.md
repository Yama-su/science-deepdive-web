## 1. 素朴な疑問

花火は火薬が爆発しているだけなのに、赤・緑・黄色・紫など様々な色を出します。単なる「火」なら、オレンジ色っぽい炎色になりそうなものですが、なぜこんなに色とりどりになるのでしょうか。

実際には、色は「金属の種類」によって決まっています。理科の授業で習う「炎色反応」と同じ原理です。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    花火の中には、色ごとに違う種類の金属の粉が入っています。
    金属は熱で燃やされると、その金属ごとに決まった色の光を出す性質があります。
    赤色にはリチウムやストロンチウム、黄色にはナトリウム、緑色にはバリウムというように、
    使う金属を変えることで色を選んでいるのです。
  </p>

## 4. わかりやすく厳密な答え

金属原子は熱エネルギーを受け取ると、原子内の電子がより高いエネルギー準位に励起されます。この励起状態は不安定なため、電子はすぐに元の低いエネルギー準位に戻りますが、そのときエネルギー準位の差に相当するエネルギーを光として放出します。

このエネルギー準位の差は元素ごとに固有の値を持つため、放出される光の波長（＝色）も元素ごとに決まった特定の値になります。これが「炎色反応」であり、花火・線香花火・ガスバーナーの炎の色が金属の種類によって変わる理由です。

代表的な金属と炎色反応の色の対応は以下の通りです。

| 元素 | 色 | 主な発光波長 |
| :--- | :--- | :--- |
| リチウム (Li) | 赤 | 約670 nm |
| ストロンチウム (Sr) | 紅色 | 約606 nm |
| カルシウム (Ca) | 橙色 | 約622 nm |
| ナトリウム (Na) | 黄色 | 約589 nm |
| バリウム (Ba) | 緑色 | 約524 nm |
| 銅 (Cu) | 青緑色 | 約505 nm |
| カリウム (K) | 紫色 | 約404 nm |

## 5. 数値シミュレーション

代表的な金属元素の発光波長をグラフにしました。波長が短いほど紫や青に近く、波長が長いほど赤に近い色になります。

![金属元素ごとの炎色反応の発光波長を示すグラフ](/assets/simulations/firework_flame_colors.png)
*図1: 元素ごとに固有の波長で発光するため、花火の色として使い分けられる*

グラフの横軸は各元素が発する光の代表的な波長(nm)で、棒の色はその波長がどんな色に見えるかをおおよそ表現しています。リチウムやストロンチウムのように波長が長い(600nm台後半)元素は赤系統に、カリウムのように波長が短い(400nm台前半)元素は紫系統に対応していることが一目でわかります。重要なのは、この波長が金属の「量」や「燃え方の勢い」では変化せず、あくまで元素の種類だけで決まる固有の値だという点です。花火職人は、この対応表をもとに使う金属を選ぶことで狙った色を作り出しています。

```python
elements = [
    ("Li (Lithium)", 670),
    ("Sr (Strontium)", 606),
    ("Na (Sodium)", 589),
    ("Ba (Barium)", 524),
    ("K (Potassium)", 404),
]
# それぞれの波長が、そのまま炎色反応で見える色に対応する
```

## 7. よくある発想は何が間違っていたのか

<div class="callout callout-intuition">
  <div class="callout-title">3大直感を検証する</div>
  <ul>
    <li><strong>「絵の具・染料を混ぜている」説の誤り：</strong>花火が燃える高温の炎の中では、色のついた有機染料はすぐに分解・燃焼してしまい、色素として機能しません。実際に使われているのは硝酸塩や炭酸塩といった無機の金属化合物です。</li>
    <li><strong>「爆発の勢いで色が変わる」説の誤り：</strong>同じ火薬量・同じ爆発力であっても、混ぜる金属の種類を変えるだけで全く違う色になることが実験的に確かめられています。勢いは炎の明るさや大きさに影響しますが、色そのものを決めるのは金属の種類です。</li>
    <li><strong>「フィルターを通している」説の誤り：</strong>花火は光源そのもの（燃えている金属の炎）が特定の波長の光を発しているのであり、観測者との間に色付きフィルムやフィルターのような仕掛けが存在するわけではありません。</li>
  </ul>
</div>

## 8. さらなる疑問

**Q. 白色や銀色に輝く花火はどうやって出しているのですか？**
アルミニウムやマグネシウムなどの金属粉末を燃やすと、特定の波長に偏らない広い波長範囲の強い光（黒体放射に近い光）が発生し、これが人間の目には白色や銀色として見えます。特定元素の炎色反応とは異なる仕組みです。

**Q. 紫や中間色の花火はどうやって作るのですか？**
単一の元素では出せない色は、複数の金属を混合して同時に燃やし、それぞれの発光色を人間の目の中で混ぜ合わせる（混色）ことで作られます。例えば紫色は、赤系のストロンチウムと青系の銅の化合物を組み合わせることで表現されることがあります。

**Q. 炎色反応は花火以外にどう役立っていますか？**
分析化学の分野では、試料を炎の中で燃やして発する光の波長を調べることで、どんな金属元素が含まれているかを特定する「炎光分析法」として実用化されています。また天文学でも、恒星などの天体が放つ光のスペクトルを分析することで、その天体を構成する元素を知る手がかりとして同じ原理が使われています。
