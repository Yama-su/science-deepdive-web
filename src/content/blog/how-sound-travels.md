## 1. 素朴な疑問

声を出したり手を叩いたりすると、その音は離れた場所にいる人にも届きます。目に見えない「音」は、一体どうやって空気中を伝わって、耳まで届いているのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「音は光と同じように、瞬時に伝わる」説</li>
    <li><strong>直感2：</strong>「音波という見えない糸のようなものが、発生源から耳まで一直線に伸びて伝える」説</li>
    <li><strong>直感3：</strong>「音の高さ（音程）によって、伝わる速さが変わる」説</li>
  </ul>

実際には、音は空気の粒（分子）どうしが次々と押し合うことで伝わる「圧力の波」であり、その速さは音の高さとは無関係に、伝わる物質（媒質）の性質だけで決まります。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    音を出すと、その場所の空気の粒がぎゅっと押し縮められます。
    押された空気の粒は、隣の空気の粒を押し、その粒がまた次の粒を押し…と、
    まるでドミノ倒しのように、押し合う動きが次々と伝わっていきます。
    この「押し合いの伝わり」が、遠くまで届く音の正体です。
  </p>
</div>

## 4. わかりやすく厳密な答え

音が伝わる速さは、媒質の「硬さ（押し縮めにくさ）」と「密度（重さ）」という、2つの性質で決まります。

<div class="math-proof-box">
<div class="proof-header">音速の公式</div>
<div class="proof-body">

音速 $v$ は、媒質の体積弾性率 $B$（押し縮めにくさを表す量。値が大きいほど圧縮しにくい）と、
密度 $\rho$（単位体積あたりの質量）を使って、

$$v = \sqrt{\frac{B}{\rho}}$$

と表される。この式の完全な導出は、9章でニュートンの運動方程式から行う。

</div>
</div>

この式は、直感的にも理解できます。媒質が「硬い」（$B$ が大きい）ほど、押されたときに強い力ですぐに隣を押し返すため、圧力の乱れが速く伝わります。一方、媒質が「重い」（$\rho$ が大きい）ほど、粒子が動き出すのに時間がかかる（慣性が大きい）ため、伝わる速さは遅くなります。重要なのは、この式のどこにも音の高さ（周波数）が入っていないという点です。同じ媒質であれば、高い音も低い音もまったく同じ速さで伝わります。

## 5. 数値シミュレーション

空気と水それぞれについて、体積弾性率と密度から予測される音速を計算し、実際に測定されている音速と比較しました。

![体積弾性率から予測した音速と実測値を比較した棒グラフ](/assets/simulations/sound_speed_media.png)
*図1: 空気・水のどちらも、公式による予測値と実測値がほぼぴったり一致する*

グラフでは、青い棒（4章の公式による予測値）とオレンジの棒（実際の測定値）が、空気・水のどちらでもほとんど同じ高さになっていることがわかります。空気では公式による予測が約340.5m/s、実測値が約343m/s、水では予測が約1483.2m/s、実測値が約1480m/sと、いずれも1%未満の誤差で一致しています。水はほとんど圧縮できない（体積弾性率が非常に大きい）ため、空気よりもはるかに速く音が伝わることも、この図からわかります。なお、鉄やガラスなどの固体では、体積弾性率に加えて「せん断（ねじれ）への強さ」も音速に寄与するため、この単純な公式だけでは音速をやや過小評価してしまいます。固体中の音速の厳密な扱いには、より複雑な弾性率が必要になります。

```python
import numpy as np

media = {
    "Air":   (1.42e5, 1.225),   # (体積弾性率B[Pa], 密度rho[kg/m^3])
    "Water": (2.2e9, 1000),
}

for name, (B, rho) in media.items():
    v = np.sqrt(B / rho)
```

## 8. さらなる疑問

**Q. 音は真空中（宇宙空間）では伝わらないと聞きますが、なぜですか？**
4章の式が示す通り、音は媒質（物質）を構成する粒子どうしの押し合いによって伝わります。真空にはそもそも押し合うべき粒子が存在しないため、圧力の乱れを伝える手段がなく、音は伝わりません。これは音と光の決定的な違いの1つで、光（電磁波）は物質がなくても伝わりますが、音は必ず何らかの媒質を必要とします。

**Q. 気温が高いと音速が速くなるのはなぜですか？**
気温が上がると、空気の分子がより激しく熱運動するようになり、体積弾性率 $B$ が実効的に大きくなります（気体の圧力・体積の関係を表す状態方程式から、温度が高いほど圧力変化に対する応答が大きくなることが導かれます）。4章の式で $B$ が大きくなれば $v$ も大きくなるため、気温が高いほど音速も速くなります。

**Q. ヘリウムガスを吸うと声が高くなるのはなぜですか？**
これは音速の変化が原因です。ヘリウムは空気よりずっと密度が低いため、4章の式で $\rho$ が小さくなり、音速 $v$ が大きくなります（ヘリウム中の音速は空気中のおよそ3倍）。声帯の振動数（音の高さの元）自体はほとんど変わりませんが、声道（喉から口までの空間）の共鳴特性が音速に依存して変化するため、結果として声がより高く、こもって聞こえるようになります。

## 9. 数式の完全な導出

4章で示した音速の公式 $v=\sqrt{B/\rho}$ を、ニュートンの運動の第2法則から、一切の飛躍なく導出します。

### ステップ1: 薄い気体の層に働く力を考える

x軸方向に伝わる音波を考えます。位置 $x$ にある、厚さ $dx$、断面積 $A$ の薄い気体の層を考え、この層が音波によって $\xi(x,t)$ だけ変位する（前後にわずかに動く）とします。

この層に働く力は、両側の圧力の差によるものです。位置 $x$ での圧力を $P(x)$ とすると、層が受ける正味の力は、

$$F = [P(x) - P(x+dx)]\, A \approx -\frac{\partial P}{\partial x}\, dx\, A$$

（左から押す力と、右から押し返す力の差です。圧力が右に向かって増加していれば、層は左向きの正味の力を受けます。）

### ステップ2: ニュートンの運動方程式を適用する

この層の質量は $\rho A\, dx$（密度×体積）です。ニュートンの第2法則 $F=ma$ を適用すると、

$$\rho A\, dx \cdot \frac{\partial^2 \xi}{\partial t^2} = -\frac{\partial P}{\partial x}\, dx\, A$$

両辺の $A\,dx$ を消去すると、

$$\rho\, \frac{\partial^2 \xi}{\partial t^2} = -\frac{\partial P}{\partial x}$$

### ステップ3: 圧力の変化を、変位 $\xi$ の式で書き直す

体積弾性率 $B$ の定義は、「圧力の変化」と「体積のひずみ（伸び縮みの割合）」の関係を表すもので、1次元では、

$$P_{\text{excess}} = -B\, \frac{\partial \xi}{\partial x}$$

（$\partial \xi/\partial x$ が正なら気体が引き伸ばされている＝圧力は下がる、というマイナスの関係です。）

これをステップ2の式に代入すると、

$$\rho\, \frac{\partial^2 \xi}{\partial t^2} = -\frac{\partial}{\partial x}\left(-B\,\frac{\partial \xi}{\partial x}\right) = B\,\frac{\partial^2 \xi}{\partial x^2}$$

### ステップ4: 標準的な波動方程式と見比べる

ステップ3で得られた式を整理すると、

$$\frac{\partial^2 \xi}{\partial t^2} = \frac{B}{\rho}\, \frac{\partial^2 \xi}{\partial x^2}$$

物理学における「波動方程式」の標準形は、

$$\frac{\partial^2 \xi}{\partial t^2} = v^2\, \frac{\partial^2 \xi}{\partial x^2}$$

（$v$ は波が伝わる速さ）という形をしています。この2つの式を見比べると、

$$v^2 = \frac{B}{\rho} \implies v = \sqrt{\frac{B}{\rho}}$$

### 結論

これが4章で使った音速の公式です。この導出の核心は、「圧力の勾配が力を生み（ステップ1・2）」「その力が、媒質の硬さに応じた変位の変化を引き起こす（ステップ3）」という2つの物理法則を組み合わせただけで、波動方程式という、圧力の乱れが一定の速さで伝わっていく現象そのものが、自然に姿を現すという点にあります。音速の公式は、天下りの結果ではなく、ニュートン力学のごく基本的な法則から導かれる必然的な帰結なのです。
