## 1. 素朴な疑問

2, 3, 5, 7, 11, 13, 17…と続く素数の並びには、一見すると何の規則性も見当たりません。次にどの数が素数になるかを予測できる、簡単な公式は存在しないのでしょうか。

実際には、個々の素数の現れ方は予測しづらいものの、素数全体の「大まかな分布」には、驚くほど正確な数学的法則が存在します。また、素数が無限に存在することも、簡単な公式が原理的に作れないことも、それぞれ厳密に証明されています。

## 4. わかりやすく厳密な答え

まず、素数が無限に存在することを確認しましょう。これは紀元前300年ごろ、古代ギリシャの数学者ユークリッドによって証明された、数学史上最も美しい証明の1つです。

<div class="math-proof-box">
<div class="proof-header">定理：素数は無限に存在する（ユークリッドの証明）</div>
<div class="proof-body">

素数が有限個しかないと仮定し、そのすべてを $p_1, p_2, \ldots, p_n$ とする。

新しい数 $N = p_1 \times p_2 \times \cdots \times p_n + 1$ を考える。

$N$ を、仮定したどの素数 $p_i$ で割っても、必ず余り $1$ が出る（$N$ は $p_i$ の倍数に $1$ を足した数だから）。
つまり $N$ は、$p_1, \ldots, p_n$ のどれによっても割り切れない。

これは2つの可能性を意味する。①$N$ 自身が新しい素数である、②$N$ は、リストにない何か別の素数で割り切れる（合成数の場合、必ず素因数を持つため）。
どちらの場合も、最初のリストに含まれない新しい素数の存在を意味し、「素数は有限個である」という仮定に矛盾する。

したがって、素数は無限に存在する。

</div>
</div>

次に「素数の分布」について、19世紀末に証明された「素数定理」という驚くべき法則があります。ある数 $x$ 以下に存在する素数の個数を $\pi(x)$ と書くと、

$$\pi(x) \sim \frac{x}{\ln x} \quad (x \to \infty)$$

という関係が成り立ちます（$\sim$ は、$x$ が大きくなるにつれて両辺の比が1に近づくことを意味します）。個々の素数がどこに現れるかは複雑で予測しづらいのに、その「個数」については、これほどシンプルな式で驚くほど正確に近似できるのです。

## 5. 数値シミュレーション

100,000までの整数について、実際の素数の個数 $\pi(x)$ と、素数定理が予測する $x/\ln x$ を比較しました。

![実際の素数計数関数と素数定理の予測を比較したグラフ](/assets/simulations/prime_counting_function.png)
*図1: 個々の素数の位置は不規則でも、その累積個数は素数定理の予測曲線にきれいに沿って増加する*

グラフの青い実線は、$x$ 以下に実際に存在する素数の個数を、エラトステネスの篩という古典的なアルゴリズムで正確に数えたものです。オレンジの破線は、素数定理が予測する $x/\ln x$ という近似式です。2つの曲線はほとんど重なるように増加しており、$x=100{,}000$ までに実際に存在する素数の個数（$9592$個）と、素数定理による予測値は、非常に近い値になっています。個々の素数が具体的にどこに現れるかを式1つで言い当てることはできませんが、「どれくらいの密度で」素数が分布しているかについては、このように驚くほど正確な法則が存在するのです。

```python
import numpy as np

N = 100000
sieve = np.ones(N + 1, dtype=bool)
sieve[0:2] = False
for i in range(2, int(N**0.5) + 1):
    if sieve[i]:
        sieve[i*i::i] = False

pi_x = np.cumsum(sieve)  # pi(x): xまでの素数の個数
# pi_x[x] は、素数定理の予測 x/log(x) に近い値になる
```

## 8. さらなる疑問

**Q. 双子素数（3と5、11と13のように、差が2の素数のペア）は無限に存在しますか？**
これは「双子素数予想」と呼ばれ、数学の未解決問題の1つです。数値実験では非常に大きな数までいくらでも双子素数が見つかっており、無限に存在するだろうと広く予想されていますが、2024年時点でも厳密な証明はまだ得られていません。2013年には数学者チャン・イータン（張益唐）が「差が7000万以下の素数のペアが無限に存在する」ことを証明し、その後この上限は大幅に改善されましたが、「差がちょうど2」というオリジナルの予想の証明には至っていません。

**Q. 素数定理は、誰がどうやって証明したのですか？**
素数定理は1896年に、フランスのジャック・アダマールとベルギーのシャルル=ジャン・ド・ラ・ヴァレー・プーサンが、それぞれ独立に証明しました。証明には複素解析学（リーマンゼータ関数の性質）が使われており、素数という一見「整数だけの」話題が、複素数の世界の道具によって解明されるという、数学の意外なつながりを示す好例です。

**Q. リーマン予想は、素数の分布とどう関係していますか？**
リーマン予想は、素数定理の近似の「誤差」がどれくらい小さいかを、より精密に述べようとする予想です。もしリーマン予想が正しいと証明されれば、素数がどれだけ規則正しく分布しているかについて、現在知られているよりもはるかに強い保証が得られます。これはミレニアム懸賞問題の1つに数えられており、証明には100万ドルの懸賞金がかけられています。

## 9. 数式の完全な導出

4章では「簡単な公式が原理的に存在しない」ことに軽く触れましたが、ここでは「どんな非定数の整数係数多項式も、すべての整数に対して素数だけを返すことはできない」ことを、一切の飛躍なく証明します。

### ステップ1: 背理法の設定

$f(n)$ を、整数係数を持つ非定数の多項式とし、すべての整数 $n=0, 1, 2, \ldots$ に対して $f(n)$ が常に素数になると仮定します。

### ステップ2: $f(0)$ に注目する

$f(0)$ は仮定によりある素数 $p$ に等しいとします（$f(0)=p$）。

### ステップ3: 多項式の性質から、割り切れる関係を導く

整数係数の多項式には、次の重要な性質があります。任意の整数 $a, b$ について、

$$a - b \mid f(a) - f(b)$$

（$a-b$ が $f(a)-f(b)$ を割り切る）が成り立ちます。これは、$f(x)=\sum c_i x^i$ の各項 $x^i$ について、$a^i - b^i$ が常に $(a-b)$ で割り切れる（因数分解 $a^i-b^i=(a-b)(a^{i-1}+a^{i-2}b+\cdots+b^{i-1})$ より）ことから従います。

この性質を、$a=kp$（$k$は任意の整数）、$b=0$ として適用すると、

$$kp - 0 \mid f(kp) - f(0)$$

つまり $p \mid f(kp) - f(0)$ です。$f(0)=p$ なので、$f(kp) - p$ は $p$ で割り切れます。したがって、

$$f(kp) \equiv f(0) \equiv 0 \pmod{p}$$

つまり、$f(kp)$ は、すべての整数 $k$ について $p$ の倍数です。

### ステップ4: $f(kp)$ が素数でいられなくなることを示す

ステップ3より、$f(kp)$ は必ず $p$ の倍数です。$f(kp)$ が素数であるためには、$p$ の倍数でありながら素数でなければならないので、$f(kp) = p$ そのものであるしかありません（$p$の倍数で素数なのは$p$自身だけだから）。

しかし $f$ は非定数の多項式なので、$k$ を十分大きくしていくと、$|f(kp)|$ はいくらでも大きくなります（非定数多項式の性質として、変数が十分大きくなれば関数値の絶対値も限りなく大きくなります）。つまり、ある十分大きな $k$ に対しては、$f(kp) \neq p$ となってしまいます。

### 結論

$f(kp)$ は $p$ の倍数でなければならない（ステップ3）にもかかわらず、$k$ が大きくなると $f(kp)$ は $p$ 自身ではいられなくなる（ステップ4）ため、$f(kp)$ は「$p$の倍数だが$p$自身ではない数」、すなわち合成数になってしまいます。これは「$f(n)$ はすべての整数に対して素数である」という、最初の仮定に矛盾します。

したがって、すべての整数に対して素数だけを返す非定数の整数係数多項式は存在しません。素数を生成する「簡単な公式」が見つからないのは、探し方が足りないからではなく、そもそも存在し得ないことが、この背理法によって証明されているのです。
