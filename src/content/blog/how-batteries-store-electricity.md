## 1. 素朴な疑問

乾電池をおもちゃに入れると、モーターが回り出します。電池の中には、あらかじめ「電気」というエネルギーの塊が、液体か固体のような形で詰め込まれているのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「電池の中には『電気』という物質そのものがぎっしり詰まっている」説</li>
    <li><strong>直感2：</strong>「電池は使っても減らない、いつまでも一定の力を出し続ける」説</li>
    <li><strong>直感3：</strong>「プラス極とマイナス極から、同じ『電気』が両方向から流れ出している」説</li>
  </ul>
</div>

実際には、電池は「電気そのもの」を貯蔵しているのではなく、2種類の異なる化学物質（電極材料）の間で自然に起こる化学反応（酸化還元反応）のエネルギーを、電気エネルギーとして取り出す装置です。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    電池の中には、電子を手放しやすい物質（マイナス極）と、電子を受け取りやすい物質（プラス極）が入っています。
    この2つを導線でつなぐと、電子はマイナス極からプラス極へ、導線を通って流れようとします。
    この電子の流れこそが「電流」であり、電池が空になるとは、この化学反応の材料（電子を出す側の物質）を使い切ってしまうことなのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

電池の仕組みは、酸化還元反応を利用した「ガルバニ電池」と呼ばれる装置で説明できます。これは、鉄がさびる現象を扱った別記事で紹介した電気化学の考え方と、まったく同じ原理に基づいています。

<div class="math-proof-box">
<div class="proof-header">電池の起電力とネルンストの式</div>
<div class="proof-body">

電池の標準状態での起電力（電圧）は、2つの電極（半反応）の標準電極電位の差として、

$$E^\circ_{\text{cell}} = E^\circ_{\text{cathode}} - E^\circ_{\text{anode}}$$

と表される。しかし実際の電池の電圧は、反応が進む（放電が進む）につれて、
反応物と生成物の濃度比 $Q$ に応じて変化する。この変化を表す式が、ネルンストの式である。

$$E = E^\circ - \frac{RT}{nF}\ln Q$$

（$R$: 気体定数、$T$: 絶対温度、$n$: 反応でやり取りされる電子の数、$F$: ファラデー定数）

</div>
</div>

放電が進むにつれて、電池内部では反応物（電気を生み出す元となる物質）が減り、生成物（反応済みの物質）が増えていきます。これにより濃度比 $Q$ が大きくなり、$\ln Q$ の項が大きくなるため、ネルンストの式の右辺全体（$E$）は徐々に小さくなっていきます。つまり電池は「電気という一定量の資源」を使い切るのではなく、化学反応が進行するにつれて、その反応の推進力（濃度差）自体がだんだん小さくなり、結果として電圧が徐々に低下していく、という仕組みで「消耗」していくのです。

## 5. 数値シミュレーション

放電が進む（反応が進行する）につれて、電池の電圧がどのように変化するかをシミュレーションしました。

![放電の進行度に対する電池電圧の変化を示すグラフ](/assets/simulations/battery_nernst_voltage.png)
*図1: 電池の電圧は、放電が進むにつれてなめらかに低下していく（一定ではない）*

グラフの横軸は放電の進み具合（0%は未使用、100%は完全に使い切った状態）、縦軸は電池の電圧です。灰色の点線で示した標準電圧（新品時の理論値）から、放電が進むにつれて電圧が徐々に下がっていく様子がわかります。特に放電の終盤（グラフの右側）で電圧の低下が急激になっているのは、ネルンストの式の対数関数 $\ln Q$ の性質上、反応物がほとんど残っていない状態では、わずかな反応の進行でも濃度比 $Q$ が劇的に変化するためです。使い古した電池の電圧が急激に落ち込み、機器が突然動かなくなる現象は、この対数関数的な変化の反映です。

```python
import numpy as np

E0 = 1.5   # 標準電池電圧
n, F, R, T = 2, 96485, 8.314, 298

progress = np.linspace(0.001, 0.999, 300)  # 放電の進み具合
Q = progress / (1 - progress)  # 反応が進むほどQ(生成物/反応物)が増加

E = E0 - (R * T) / (n * F) * np.log(Q)
```

## 8. さらなる疑問

**Q. 充電池（二次電池）と使い切りの乾電池（一次電池）は何が違うのですか？**
どちらも4章で説明したネルンストの式に従う点は共通していますが、充電池は放電時の化学反応が「可逆的」に設計されています。外部から逆向きに電流を流すことで、放電時に進んだ化学反応を逆戻しし、反応物を元の状態に戻す（充電する）ことができます。乾電池は反応が実質的に不可逆で、一度反応が進んでしまうと元に戻せません。

**Q. 電池を並列につなぐ場合と直列につなぐ場合で、何が変わりますか？**
直列につなぐと、それぞれの電池の起電力（4章の $E$）が単純に足し合わされ、全体の電圧が高くなります。並列につなぐと、電圧自体は変わりませんが、電流を供給できる総容量（反応物の総量）が増えるため、同じ電圧のまま、より長時間電気を供給し続けられるようになります。

**Q. 電池の温度が低いと性能が落ちるのはなぜですか？**
4章のネルンストの式に温度 $T$ が直接含まれていることに加え、低温では電極内部でのイオンの移動速度（反応速度）自体も遅くなります。真冬に乾電池の性能が落ちるのは、化学反応そのものが低温で進みにくくなることが主な原因です。

## 9. 数式の完全な導出

4章で使ったネルンストの式 $E=E^\circ-\dfrac{RT}{nF}\ln Q$ を、化学熱力学の基本関係式から、一切の飛躍なく導出します。

### ステップ1: 反応のギブズ自由エネルギーと、濃度の関係を確認する

化学反応のギブズ自由エネルギー変化 $\Delta G$ は、標準状態での値 $\Delta G^\circ$ に加えて、実際の反応物・生成物の濃度比 $Q$（反応商）によって、

$$\Delta G = \Delta G^\circ + RT\ln Q$$

という補正がかかることが、化学熱力学の基本法則として知られています。

### ステップ2: ギブズ自由エネルギーと、電池の起電力を結びつける

別記事「鉄はなぜさびるのか」でも使った関係式、$\Delta G=-nFE$（ギブズ自由エネルギー変化と、電池の起電力の関係）を、ステップ1の式のそれぞれの項に適用します。

$$-nFE = -nFE^\circ + RT\ln Q$$

### ステップ3: 両辺を $-nF$ で割る

$$E = E^\circ - \frac{RT}{nF}\ln Q$$

### 結論

これが4章で示したネルンストの式です。この導出からわかる通り、ネルンストの式は独立した新しい法則ではなく、「反応のギブズ自由エネルギーが濃度によって変化する」という熱力学の基本事実（ステップ1）と、「ギブズ自由エネルギーと起電力は比例関係にある」という電気化学の基本関係（ステップ2）を組み合わせただけで、自然に導かれる結果です。電池が放電するにつれて電圧が低下していくのは、この2つの基本法則が組み合わさった、避けられない帰結なのです。
