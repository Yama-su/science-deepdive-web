## 1. 素朴な疑問

どんなに細長い三角形でも、どんなに大きな三角形でも、3つの内角を足し合わせると必ず180度になります。形も大きさも自由に選べるはずなのに、なぜ答えがいつも同じ180度に決まるのでしょうか。

分度器で測る方法には必ず誤差が入るため、それだけでは「常に正確に180度である」ことの証明にはなりません。実はこの事実は、平行線に関するある性質から、誤差ゼロで完全に証明できます。

## 4. わかりやすく厳密な答え

三角形 $ABC$ の頂点 $C$ を通り、辺 $AB$ に平行な直線を引きます。この作図によって、角度の関係が明らかになります。

<div class="math-proof-box">
<div class="proof-header">定理：三角形の内角の和は180度</div>
<div class="proof-body">

頂点 $C$ を通り辺 $AB$ に平行な直線を引く。このとき、平行線と辺 $AC$（および辺 $BC$）が作る「錯角」の性質により、

- 頂点 $C$ でこの平行線と辺 $AC$ がなす角は、頂点 $A$ の内角 $\angle A$ と等しい
- 頂点 $C$ でこの平行線と辺 $BC$ がなす角は、頂点 $B$ の内角 $\angle B$ と等しい

頂点 $C$ における3つの角（$\angle A$ に等しい角、三角形の内角 $\angle C$、$\angle B$ に等しい角）は、1本の直線上に並んでおり、直線がなす角の合計は $180^\circ$ である。したがって、

$$\angle A + \angle C + \angle B = 180^\circ$$

</div>
</div>

この証明の急所は「錯角が等しい」という性質であり、これは2本の直線が平行であるときに限って成り立つ性質です。つまり「三角形の内角の和が180度になる」という事実は、実は「平行線とは何か」という、幾何学の最も基礎的な前提（平行線公理）に支えられているのです。

## 5. 数値シミュレーション

平面上にランダムに配置した200個の三角形について、内角の和をコンピュータで実際に計算しました。

![200個のランダムな三角形の内角の和のヒストグラム、すべて180度に集中](/assets/simulations/triangle_angle_sum_check.png)
*図1: 頂点の位置を完全にランダムに選んでも、内角の和は例外なく180度になる*

グラフは、200個のまったく形の異なるランダムな三角形について、それぞれの内角の和を計算し、その分布をヒストグラムにしたものです。もし三角形の形によって内角の和が変わるなら、このヒストグラムは横方向に広がった分布になるはずです。しかし実際には、赤い破線で示した180度の位置に、すべての結果が針のように鋭く集中しています。実際にコンピュータで計算した200個の値は、最小でも179.99999999999918度、最大でも180.00000000000693度という範囲に収まっており、この極めて小さなばらつきはコンピュータの計算に伴う丸め誤差にすぎません。理論上は寸分の狂いもなく、常にちょうど180度になります。

```python
import numpy as np

def triangle_angle_sum(pts):
    total = 0
    for i in range(3):
        p_prev, p_cur, p_next = pts[i-1], pts[i], pts[(i+1) % 3]
        v1, v2 = p_prev - p_cur, p_next - p_cur
        cos_a = np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))
        total += np.degrees(np.arccos(np.clip(cos_a, -1, 1)))
    return total
# どんなptsを与えても、totalは常に180に極めて近い値になる
```

## 8. さらなる疑問

**Q. 球の表面に描いた三角形でも、内角の和は180度になりますか？**
なりません。地球儀の表面に、北極点から赤道まで伸びる2本の経線と、その間の赤道の一部を結んでできる三角形を考えると、内角の和は180度を超えます（例えば北極点の角度を90度、赤道上の2つの角度も90度ずつにできるケースでは合計270度）。これは球面が「曲がっている」ためで、4章の証明で使った「平行線」という概念自体が、曲がった面の上では平面上と同じようには成り立たないことに由来します。

**Q. なぜ「平行線公理」が三角形の内角の和と関係あるのですか？**
4章の証明は「頂点を通り、向かいの辺に平行な直線がただ1本だけ引ける」という前提（平行線公理、あるいはプレイフェアの公理と呼ばれる形）に依存しています。実は、この平行線公理と「三角形の内角の和は180度」という命題は、論理的に同値であることが知られています。つまり一方を仮定すれば他方が証明でき、その逆も成り立ちます。

**Q. 平行線公理を採用しない幾何学もあるのですか？**
あります。「非ユークリッド幾何学」と呼ばれる体系では、平行線公理の代わりに別の前提を採用します。球面のような正の曲率を持つ空間（楕円幾何学）では三角形の内角の和は常に180度より大きく、馬の鞍のような負の曲率を持つ空間（双曲幾何学）では常に180度より小さくなります。19世紀にこれらの幾何学が発見されたことで、「平行線公理は本当に唯一絶対の真実なのか」という、2000年以上信じられてきた常識が根本から問い直されることになりました。

## 9. 数式の完全な導出

4章の証明では「錯角は等しい」という性質を使いましたが、この性質自体がなぜ成り立つのかを、平行線の定義まで遡って確認します。

### ステップ1: 平行線公理を確認する

ユークリッド幾何学の土台となる公理（現代的にはプレイフェアの公理と呼ばれる形）は、次のように述べられます。

**平行線公理：** 直線 $\ell$ とその上にない点 $P$ が与えられたとき、$P$ を通り $\ell$ に平行な直線は、ちょうど1本だけ存在する。

この公理があるからこそ、4章の証明で「頂点Cを通り、辺ABに平行な直線」を、迷いなくただ1本引くことができます。

### ステップ2: 「錯角が等しい」ことを、平行線の定義から示す

2本の平行な直線 $\ell_1, \ell_2$ に、別の1本の直線（横断線）が交わっているとします。錯角とは、横断線を挟んで反対側にできる、向かい合う角のペアのことです。

錯角が等しいことは、次のように背理法で示せます。もし錯角が等しくないと仮定すると、横断線ともう一方の角度をなす別の直線を引いたとき、その直線は元の直線 $\ell_2$ とは異なる角度を持つことになり、これは「点を通り $\ell_1$ に平行な直線がもう1本存在する」ことを意味してしまいます。しかしステップ1の平行線公理は「平行な直線はちょうど1本しかない」と述べているため、これは矛盾です。したがって、錯角は等しくなければなりません。

### ステップ3: 頂点Cのまわりの角度の合計が180度であることを確認する

4章の証明で、頂点 $C$ を通る平行線の上には、3つの角（$\angle A$に等しい角、$\angle C$自身、$\angle B$に等しい角）が隙間なく並んでいました。1つの直線上に並ぶ角度（半回転分の角度）の合計が $180^\circ$ であることは、「直線」という図形の定義そのもの（一直線上の点は、ちょうど半回転＝180度の角度をなす）から成り立つ、幾何学の最も基本的な事実です。

### 結論

ステップ1（平行線はただ1本）→ ステップ2（だから錯角は等しい）→ ステップ3（だから頂点でのの角度の合計は180度）という一本道の論理をたどることで、「三角形の内角の和は180度である」という事実全体が、平行線公理というたった1つの前提から漏れなく導かれることが確認できました。逆に言えば、8章で触れた球面のような空間では、この土台となる平行線公理そのものが成り立たないため、内角の和が180度からずれるという結論も、驚くには当たらない自然な帰結なのです。
