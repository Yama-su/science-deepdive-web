## 1. 素朴な疑問

足の速いアキレスが、少し先を歩く足の遅い亀を追いかけます。古代ギリシャの哲学者ゼノンは、「アキレスが亀のいた場所にたどり着く頃には、亀はさらに少し先に進んでいる。この繰り返しは無限に続くので、アキレスは永遠に亀に追いつけない」と論じました。しかし現実には、アキレスは簡単に亀を追い越せるはずです。この理屈のどこに問題があるのでしょうか。

    <li><strong>直感3：</strong>「現実にアキレスは亀に追いつくのだから、この議論自体がただ間違っているだけ」説（なぜ間違って見えるのかは説明できない）</li>
  </ul>

実際には、ゼノンの議論の「手順」自体は正しいのですが、「無限の手順＝無限の時間」という暗黙の思い込みが誤りです。無限に多くのステップがあっても、それぞれのステップにかかる時間がどんどん短くなっていけば、合計の時間は有限の値に収束することがあります。

## 4. わかりやすく厳密な答え

ゼノンが説明した手順に従って、アキレスが亀に追いつくまでの時間を、無限級数として実際に計算してみましょう。

<div class="math-proof-box">
<div class="proof-header">ゼノンの手順による、追いつくまでの時間の合計</div>
<div class="proof-body">

亀の最初のリードを $d_0$、アキレスの速さを $v_A$、亀の速さを $v_T$（$v_T<v_A$）とする。
アキレスが亀の元の位置に着くまでの時間を $t_1=d_0/v_A$ とすると、その間に亀は
$v_Tt_1 = r\,d_0$（ただし $r=v_T/v_A$）だけ先に進む。

この手順を繰り返すと、$n$回目のステップにかかる時間は $t_n = r^{n-1}t_1$ となり、
公比 $r$（$0<r<1$）の等比数列をなす。ゼノンの手順にかかる合計時間は、この無限級数の和である。

$$T_{\text{total}} = \sum_{n=1}^{\infty} t_1 r^{n-1} = \frac{t_1}{1-r}$$

（等比級数の和の公式。$0<r<1$ なので、この無限級数は有限の値に収束する。）

</div>
</div>

つまり、ゼノンが指摘した「無限回のステップ」自体はまったく正しいのですが、それぞれのステップにかかる時間が公比 $r$（$1$未満）で急速に小さくなっていくため、無限個の時間をすべて足し合わせても、合計は無限大にはならず、$t_1/(1-r)$ というきちんとした有限の値に収まります。「無限のステップ」と「無限の時間」は、まったく別の概念なのです。

## 5. 数値シミュレーション

亀の最初のリードを100m、アキレスの速さを秒速10m、亀の速さを秒速2mとして、ゼノンの手順を実際に20ステップまで計算し、時間の合計がどう変化していくかをシミュレーションしました。

![ゼノンの手順のステップ数に対する、累積時間の変化を示すグラフ](/assets/simulations/zeno_paradox_convergence.png)
*図1: ステップを重ねるごとに時間の合計は増えていくが、有限の値（赤い破線）に収束していく*

グラフを見ると、ステップを重ねるごとに累積時間はどんどん増えていきますが、その増え方は急速に小さくなっていき、赤い破線で示した「本当にアキレスが追いつく時刻」（12.5秒）に、限りなく近づいていきます。実際にこのシミュレーションでは、わずか20ステップの時点で、累積時間はすでに真の値と小数点以下14桁まで一致するほど収束しています。無限に続くはずのステップが、実質的にはあっという間に「終わった」のと同じ状態に到達するのです。

```python
d0, vA, vT = 100.0, 10.0, 2.0
r = vT / vA
t1 = d0 / vA

n_steps = 20
times = [t1 * r**(n-1) for n in range(1, n_steps + 1)]
cumulative_time = sum(times)  # 真の値 d0/(vA-vT)=12.5 に極めて近づく
```

## 8. さらなる疑問

**Q. ゼノンには、他にも似たようなパラドックスがあるのですか？**
はい、「二分法のパラドックス」が有名です。「ある地点に到達するには、まずその半分の距離を進まなければならず、さらにその半分を進まなければならず…」と、目的地に着く前に無限回の中間地点を通過する必要があるため、そもそも運動を始めることすらできないはず、という議論です。これもアキレスと亀の問題と同じく、$1/2+1/4+1/8+\cdots=1$ という収束する等比級数によって解決されます。

**Q. 「無限級数が収束する」ということを、誰が最初に厳密に証明したのですか？**
古代ギリシャの時代から、アルキメデスなどが特定の級数の和を扱っていましたが、極限や収束という概念が現代のような厳密さで定式化されたのは、19世紀のコーシーやワイエルシュトラスらによる「解析学の厳密化」と呼ばれる運動によってです。ゼノンが紀元前5世紀に提起した問いに、数学が完全な答えを用意するまでに、2000年以上の歳月がかかったことになります。

**Q. 等比級数の公式 $t_1/(1-r)$ は、いつでも使えるのですか？**
いいえ、公比 $r$ の絶対値が1未満（$|r|<1$）のときにだけ、この無限級数は収束し、この公式が使えます。もし $r\ge 1$（例えば亀の方がアキレスより速い場合）であれば、級数は発散してしまい、合計は無限大になります。ゼノンの問題設定でアキレスが亀より速い（$v_T<v_A$、つまり $r<1$）ことが、そもそも問題が有限の時間で解決するための、数学的に必要な条件だったのです。

## 9. 数式の完全な導出

4章で使った等比級数の和の公式 $T_{\text{total}}=t_1/(1-r)$ を、一切の飛躍なく導出します。

### ステップ1: 部分和を定義する

最初の $n$ 項までの合計（部分和）を $S_n$ とします。

$$S_n = t_1 + t_1 r + t_1 r^2 + \cdots + t_1 r^{n-1}$$

### ステップ2: $S_n$ に公比 $r$ を掛ける

$$rS_n = t_1 r + t_1 r^2 + t_1 r^3 + \cdots + t_1 r^n$$

### ステップ3: $S_n$ から $rS_n$ を引く

$$S_n - rS_n = t_1 - t_1 r^n$$

（右辺以外の中間の項は、ステップ1とステップ2の式で共通しているため、すべて打ち消し合います。）

左辺を整理すると、

$$S_n(1-r) = t_1(1-r^n)$$

$$S_n = \frac{t_1(1-r^n)}{1-r}$$

### ステップ4: $n\to\infty$ の極限を考える

$0<r<1$ のとき、$n$ を大きくしていくと $r^n$ はどんどん0に近づいていきます（例えば $r=0.2$ なら、$r^n$ は $0.2, 0.04, 0.008, \ldots$ と急速に0に近づきます）。したがって、

$$\lim_{n\to\infty} r^n = 0$$

これをステップ3の式に代入すると、

$$T_{\text{total}} = \lim_{n\to\infty} S_n = \frac{t_1(1-0)}{1-r} = \frac{t_1}{1-r}$$

### 結論

これが4章で示した無限級数の和の公式です。この導出のポイントは、無限個の項をいきなり全部足そうとするのではなく、まず有限個（$n$個）の部分和 $S_n$ を求め、その後で $n$ を無限に大きくする「極限」を取るという、2段階の手順にあります。この「部分和の極限として無限級数を定義する」という考え方こそが、ゼノンの時代には存在しなかった、現代数学が無限を厳密に扱うための、決定的な道具なのです。
