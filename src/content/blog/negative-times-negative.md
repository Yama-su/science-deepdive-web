## 1. 素朴な疑問

$(-2) \times (-3) = 6$ のように、マイナスの数どうしを掛けるとプラスになる、というルールを学校で習います。しかし「なぜそうなるのか」を、丸暗記ではなく理屈で説明できるでしょうか。

例え話は直感をつかむのに便利ですが、それだけでは「証明」にはなりません。実は、数の基本的な性質（計算法則）だけから、一切の例外なく導き出せる事実なのです。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    $3 \times (-2)$, $2\times(-2)$, $1\times(-2)$ ... と、左の数を1ずつ減らしていくと、答えは $-6, -4, -2$ ... と2ずつ増えていきます。
    このパターンをそのまま続けると、$0\times(-2)=0$ の次は $(-1)\times(-2)=2$ にならなければ、規則が壊れてしまいます。
    つまり「マイナス×マイナス＝プラス」は、これまでの計算のルールを壊さないために、そうならざるを得ないのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

この事実は、実は「分配法則」という、算数・数学の最も基本的なルールだけから証明できます。

<div class="math-proof-box">
<div class="proof-header">定理：負の数どうしの積は正になる</div>
<div class="proof-body">

任意の正の数 $a, b$ について、$(-a) \times (-b) = a \times b$ が成り立つことを示す。

まず、任意の数 $x$ について $x \times 0 = 0$ が成り立つことと、分配法則 $x\times(y+z) = xy+xz$ を使う。

$$(-a) \times (-b) + (-a) \times b = (-a) \times \bigl((-b) + b\bigr) = (-a) \times 0 = 0$$

この式は $(-a)\times(-b)$ が $(-a)\times b$ の加法逆元（符号を反転させたもの）であることを意味する。

同様に $(-a) \times b + a \times b = \bigl((-a)+a\bigr)\times b = 0 \times b = 0$ なので、$(-a)\times b$ は $a\times b$ の加法逆元である。

したがって $(-a)\times(-b)$ は「$a\times b$ の加法逆元」の、さらに加法逆元であり、これは $a \times b$ 自身に等しい。

$$(-a) \times (-b) = a \times b$$

</div>
</div>

この証明は「マイナスとマイナスが打ち消し合う」という比喩ではなく、「ある数の加法逆元の、さらに加法逆元は元の数自身に戻る」という、数の基本性質を2回使っているだけです。

## 8. さらなる疑問

**Q. 「プラス×マイナス＝マイナス」の方も同じように証明できますか？**
はい。4章の証明の前半部分（$(-a)\times b$ が $a\times b$ の加法逆元であることを示した部分）が、まさに「正の数×負の数＝負の数」の証明になっています。同じ分配法則の使い方一つで、両方の符号の規則が芋づる式に証明できます。

**Q. 複素数や行列のように、数以外のものを「掛ける」場合にも同じ規則は成り立ちますか？**
分配法則が成り立つ数学的な体系（環や体と呼ばれる構造）であれば、今回の証明はそのまま通用します。複素数の掛け算や、多くの行列の演算でも、同様に「負の元」どうしの積に関する類似の性質が証明できます。証明の道具が「打ち消し合うイメージ」ではなく「公理」であることの強みがここにあります。

**Q. この性質が成り立たない数学的な構造はあるのですか？**
分配法則を満たさない、あるいは加法逆元が存在しない特殊な代数構造（半環と呼ばれるものなど）では、この証明の前提が崩れるため、同様の結論を保証できません。私たちが日常使う整数・有理数・実数・複素数はすべて分配法則を満たす「環」や「体」の一種なので、安心してこのルールを使うことができます。

## 9. 数式の完全な導出

4章の証明では2つのステップを使いましたが、それぞれの根拠となる基本性質（加法逆元の一意性）をさらに掘り下げ、完全に自己完結した証明にします。

### 準備: 加法逆元の一意性

まず、ある数 $x$ に対して「足すと0になる数」（加法逆元、$-x$ と書く）は、ただ1つしか存在しないことを確認します。もし $y$ と $z$ がどちらも $x$ の加法逆元だとすると、$x+y=0$ かつ $x+z=0$ なので、

$$y = y + 0 = y + (x+z) = (y+x) + z = 0 + z = z$$

となり、$y=z$ が示されます。つまり「$x$ に足して0になる数」は一意に決まります。この事実を使うと、「ある数 $w$ が $x+w=0$ を満たすと確認できれば、$w$ は必ず $-x$ である」と言い切れるようになります。

### ステップ1: $(-a)\times(-b)$ が $(-a)\times b$ の加法逆元であることを示す

分配法則を使うと、

$$(-a)\times(-b) + (-a)\times b = (-a)\times\bigl((-b)+b\bigr)$$

$(-b)+b=0$ なので（加法逆元の定義そのもの）、右辺は $(-a)\times 0$ になります。ここで「どんな数に $0$ を掛けても $0$ になる」という性質（これ自体、ゼロ除算の記事で示したのと同じ手法で分配法則から証明できる基本性質です）を使うと、

$$(-a)\times(-b) + (-a)\times b = 0$$

準備した「加法逆元の一意性」により、この式は「$(-a)\times(-b)$ は $(-a)\times b$ の加法逆元である」ことを厳密に意味します。式で書くと、

$$(-a)\times(-b) = -\bigl((-a)\times b\bigr)$$

### ステップ2: $(-a)\times b$ が $a\times b$ の加法逆元であることを示す

同じ手順を、今度は右側の掛け算に着目して繰り返します。

$$(-a)\times b + a\times b = \bigl((-a)+a\bigr)\times b = 0 \times b = 0$$

同じく加法逆元の一意性から、

$$(-a)\times b = -(a\times b)$$

### ステップ3: 2つの結果をつなぎ合わせる

ステップ1の結果にステップ2の結果を代入します。

$$(-a)\times(-b) = -\bigl((-a)\times b\bigr) = -\bigl(-(a\times b)\bigr)$$

最後に、「ある数の加法逆元の、さらに加法逆元は、元の数自身に戻る」という性質（これも一意性から容易に示せます：$-(-x)$ は「$-x$ に足すと0になる数」であり、$x + (-x) = 0$ なので $x$ もその条件を満たし、一意性より $-(-x)=x$）を使うと、

$$-\bigl(-(a\times b)\bigr) = a\times b$$

### 結論

以上をつなげると、

$$(-a)\times(-b) = a\times b$$

が、加法逆元の一意性と分配法則という、ごく基本的な2つの性質だけから、一切の例外なく証明されました。この証明の中に「打ち消し合う」といった比喩は一度も登場しません。使ったのは「同じものに足して0になる数はただ1つしかない」という地味だけれど強力な事実だけであり、これこそが「マイナス×マイナス＝プラス」という規則の、揺るぎない土台なのです。
