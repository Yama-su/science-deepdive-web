## 1. 素朴な疑問

ジェットコースターのループ（宙返り）では、頂上で車両が完全に逆さまになります。座席から体が投げ出されそうなものですが、実際には落ちてきません。この不思議な現象は、どういう仕組みで成り立っているのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「車両が軽いから落ちない。重ければ落ちてしまう」説</li>
    <li><strong>直感2：</strong>「ループの頂上でも、レールが常に車両を上から強く押さえつけているから安全」説</li>
    <li><strong>直感3：</strong>「スピードが速すぎると、逆に頂上で振り落とされてしまう」説</li>
  </ul>
</div>

実際には、車両の重さは落ちるかどうかに一切関係しません。そして「速すぎると危険」というのは正反対で、危険なのは「遅すぎる」場合です。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>

    これは、水が円を描くように動き続けるためには、常に円の中心に向かう力（向心力）が必要で、
    バケツの底が水を押す力に加えて、重力そのものがちょうどよい「中心に向かう力」として働いてくれるからです。
    ジェットコースターも同じ原理で、頂上で十分な速さがあれば、重力が向心力の役割を果たし、レールから離れずに済むのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

円運動を続けるためには、常に円の中心に向かう力（向心力）が必要です。ループの頂上では、重力とレールからの垂直抗力の両方が、この向心力を生み出す役割を担います。

<div class="math-proof-box">
<div class="proof-header">ループ頂上での最小速度</div>
<div class="proof-body">

半径 $r$ のループの頂上（車両が逆さまになる位置）で、車両に働く力は、下向きの重力 $mg$ と、
レールが車両を（中心方向である下向きに）押す垂直抗力 $N$ の2つである。
円運動を維持するために必要な向心力は $mv^2/r$ なので、

$$N + mg = \frac{mv^2}{r}$$

レールは車両を「押す」ことしかできず、$N$ は0以上でなければならない（$N\ge0$）。
この式を $N$ について解くと $N = mv^2/r - mg$ となり、$N\ge0$ の条件から、

$$v^2 \ge gr \implies v \ge \sqrt{gr}$$

</div>
</div>

この式が示す重要な点は、必要な最小速度 $v_{\min}=\sqrt{gr}$ の中に、車両の質量 $m$ がまったく含まれていないということです。つまり、頂上で必要な速さは、車両が空でも満員でも、まったく同じです。また、速度が最小速度を下回ると、$N$ が負の値になろうとしますが、レールは車両を「引っ張る」ことができない（$N$を負にはできない）ため、実際にはレールから車両が離れてしまい、放物線を描いて落下してしまいます。「速すぎる」ことは危険なのではなく、「遅すぎる」ことこそが危険なのです。

## 5. 数値シミュレーション

ループの半径に対する頂上での最小必要速度と、ループを1周する間に垂直抗力がどう変化するかをシミュレーションしました。

![ループ半径と最小速度の関係、およびループ内の垂直抗力の変化を示す2つのグラフ](/assets/simulations/loop_coaster_forces.png)
*図1: 左はループ半径と頂上での最小速度の関係、右はループ内での垂直抗力の変化（180度＝頂上で最小になる）*

左のグラフは、ループの半径が大きいほど、頂上で必要な最小速度も大きくなることを示しています（$\sqrt{r}$ に比例するため、半径を4倍にすると必要速度は2倍になります）。右のグラフは、車両がループの底（0度）から頂上（180度）を通って再び底に戻るまでの、レールが車両を押す力（垂直抗力）の変化を表しています。垂直抗力は頂上（180度）でちょうど最小値（この例では臨界速度ちょうどでゼロ）になっており、ループの中で最も「レールへの密着度が低くなる」危険な瞬間が、直感通り頂上であることが確認できます。

```python
import numpy as np

g = 9.8
r = 10  # メートル

v_min_top = np.sqrt(g * r)  # 頂上での最小速度
print(v_min_top * 3.6, "km/h")  # 時速に変換
```

## 7. よくある発想は何が間違っていたのか

<div class="callout callout-intuition">
  <div class="callout-title">3大直感を検証する</div>
  <ul>

    <li><strong>「常にレールが強く押さえつけている」説の誤り：</strong>図1右のグラフが示す通り、垂直抗力はループの底で最大になり、頂上に近づくにつれて小さくなっていきます。頂上ではレールが車両を押す力が最も弱くなる（臨界速度ちょうどではゼロになる）瞬間なのです。</li>
    <li><strong>「速すぎると振り落とされる」説の誤り：</strong>4章の不等式 $v\ge\sqrt{gr}$ が示す通り、危険なのは速度がこの最小値を**下回る**場合です。速度が速いほど、必要な向心力に対して重力だけでは足りない分をレールがしっかり補ってくれる（$N$の値が大きくなる）ため、むしろ安全性は高まります。</li>
  </ul>

## 8. さらなる疑問

**Q. ループの底では、乗客はどうして体が重く感じるのですか？**
図1右のグラフの角度0度（底）付近を見ると、垂直抗力 $N$ が最も大きな値になっています。乗客が体で感じる「重さ」は、実際の重力ではなく、座席（レール）から受ける垂直抗力の大きさに対応するため、底では通常の何倍もの力で座席に押しつけられ、体が重く感じられるのです。

**Q. 実際のジェットコースターのループは、なぜ真円ではなく、しずく型（クロソイド曲線）が多いのですか？**
真円のループでは、底に近い部分（垂直抗力が最も大きくなる場所）で、乗客に極端に大きな力（Gフォース）がかかってしまいます。しずく型の曲線を使うことで、底の曲率半径を大きく（緩やかに）し、頂上の曲率半径を小さくすることで、コース全体を通じてかかる力をより均等にし、乗り心地と安全性を両立させる工夫がされています。

**Q. 頂上を通過するために必要な速度は、コースターがどれくらいの高さから出発すれば得られますか？**
エネルギー保存則（位置エネルギーと運動エネルギーの変換）を使うと、必要な出発の高さを逆算できます。実際のジェットコースター設計では、4章で示した頂上での最小速度の条件に、摩擦や空気抵抗による損失分の余裕を持たせた上で、出発地点の高さが決められています。

## 9. 数式の完全な導出

4章では頂上だけを扱いましたが、ここではループの任意の角度における垂直抗力 $N(\theta)$ を、エネルギー保存則とニュートンの運動方程式から、一切の飛躍なく導出します。

### ステップ1: 角度とその位置での高さの関係を決める

ループの底を角度 $\theta=0$、頂上を $\theta=\pi$（180度）とし、中心からの半径を $r$ とします。底を基準（高さ0）とすると、角度 $\theta$ の位置での高さは、円の幾何学的な関係から、

$$h(\theta) = r(1-\cos\theta)$$

（$\theta=0$ で $h=0$、$\theta=\pi$ で $h=2r$、つまり頂上は底からループの直径分の高さにあることを表しています。）

### ステップ2: エネルギー保存則から、角度θでの速さを求める

底での速さを $v_0$ とすると、エネルギー保存則（摩擦・空気抵抗を無視）より、

$$\frac{1}{2}v_0^2 = \frac{1}{2}v(\theta)^2 + g\,h(\theta)$$

$v(\theta)^2$ について解くと、

$$v(\theta)^2 = v_0^2 - 2gr(1-\cos\theta)$$

### ステップ3: 角度θでの、重力の向心方向成分を求める

角度 $\theta$ の位置で、中心方向を向く重力の成分は、幾何学的な関係から $-mg\cos\theta$ と表せます（$\theta=0$（底）では $-mg$、つまり重力は中心から遠ざかる向きにフルに働き、$\theta=\pi$（頂上）では $+mg$、つまり重力は中心向きにフルに働くことに対応しています）。

### ステップ4: ニュートンの運動方程式（向心方向）を立てる

向心方向の運動方程式は、

$$N(\theta) + (-mg\cos\theta) = \frac{mv(\theta)^2}{r}$$

$N(\theta)$ について解くと、

$$N(\theta) = \frac{mv(\theta)^2}{r} + mg\cos\theta$$

### ステップ5: ステップ2の結果を代入し、整理する

$$N(\theta) = \frac{m\bigl[v_0^2-2gr(1-\cos\theta)\bigr]}{r} + mg\cos\theta = \frac{mv_0^2}{r} - 2mg + 2mg\cos\theta + mg\cos\theta$$

$$N(\theta) = \frac{mv_0^2}{r} - 2mg + 3mg\cos\theta$$

### ステップ6: $N(\theta)$ が最小になる角度を確認する

この式を見ると、$N(\theta)$ は $\cos\theta$ の1次関数（係数 $3mg>0$）になっています。$\cos\theta$ が最小になるのは $\theta=\pi$（頂上）のとき（$\cos\pi=-1$）なので、$N(\theta)$ もちょうど頂上で最小値を取ります。これは、図1右のグラフで頂上（180度）が最も低い値になっていたことと完全に一致します。

### 結論

頂上（$\theta=\pi$）で $N=0$（レールからの力がぎりぎりゼロ）となる条件を、ステップ5の式に代入すると、

$$0 = \frac{mv_0^2}{r} - 2mg - 3mg \implies v_0^2 = 5gr \implies v_0 \ge \sqrt{5gr}$$

これは、ループの**底**を通過する時点で必要な最小速度を表しており、4章で求めた「頂上での最小速度 $\sqrt{gr}$」とあわせて、ループ全体の安全性を保証する2つの重要な条件が、同じ物理法則から完全に導出されました。
