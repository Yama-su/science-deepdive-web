## 1. 素朴な疑問

円周率(π)は3.14159265...と、どこまで計算しても割り切れず、規則性もなく数字が続きます。円という身近でシンプルな図形の性質なのに、なぜこんなに複雑な数になるのでしょうか。

    <li><strong>直感3：</strong>「円が完全な図形ではないから」説</li>

実際には、円周率が終わらないことは数学的に**証明されている事実**であり、単に「計算が終わっていない」わけではありません。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    円周率は「分数では絶対に表せない数」であることが証明されています。
    整数÷整数で表せる数（分数）は、必ずどこかで割り切れるか、同じ数字の繰り返しになります。
    円周率はそのどちらにも当てはまらないことがわかっているので、永遠に終わらない、規則性のない数字が続くのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

円周率のように、分数 $\frac{p}{q}$（$p, q$は整数）の形で表せない数を「無理数」と呼びます。円周率が無理数であることは1761年にランベルトによって証明されました。

<div class="math-proof-box">
<div class="proof-header">有理数と無限小数の関係</div>
<div class="proof-body">

分数で表せる数（有理数）を小数で表すと、必ず有限小数になるか、
ある桁以降で同じ数字の並びが無限に繰り返される循環小数になる。

$$\frac{1}{3} = 0.333\ldots \quad \frac{1}{7} = 0.142857142857\ldots$$

円周率 $\pi$ はこのどちらにも当てはまらない（非循環無限小数）ことが証明されているため、
分数では表せない無理数である。

</div>
</div>

さらに円周率は「超越数」でもあることが1882年にリンデマンによって証明されています。これは、円周率がどんな有理数係数の代数方程式の解にもならないという、無理数よりもさらに強い性質です。この事実は「与えられた円と同じ面積の正方形を、定規とコンパスだけで作図できるか」という古代からの難問（円積問題）が**不可能である**ことの証明にもつながりました。

## 5. 数値シミュレーション

円周率は「モンテカルロ法」というランダムな試行を使った方法でも近似的に求めることができます。正方形の中にランダムな点を大量に打ち、その点が内接する円の中に入る割合から円周率を推定します。

![モンテカルロ法による円周率の近似シミュレーション](/assets/simulations/pi_monte_carlo.png)
*図1: 左は正方形内にランダムに打った点(円の内側/外側で色分け)、右は点の数を増やすほど推定値が3.14159...に近づいていく様子*

左図は一辺2の正方形の中にランダムな点を3000個打ち、中心から半径1の円の内側に入った点を青、外側に落ちた点をオレンジで塗り分けたものです。正方形の面積は4、円の面積は $\pi$ なので、円の中に入った点の割合はおおよそ $\pi / 4$ に近づくはずです。この割合を4倍すれば円周率の近似値が得られます。右図はこの考え方に基づき、点の数を10個から3000個まで対数目盛りで増やしていったときの推定値の変化を示しています。点が少ないうちは赤い破線（真の $\pi$ の値）から大きくずれていますが、点数が増えるにつれて徐々に真の値へと近づいていく様子がわかります。ただし、これはあくまで統計的な近似であり、円周率の桁を厳密に求める方法ではありません。

```python
import numpy as np

rng = np.random.default_rng(42)
x = rng.uniform(-1, 1, 3000)
y = rng.uniform(-1, 1, 3000)
inside = x**2 + y**2 <= 1

pi_estimate = 4 * np.mean(inside)
# 点の数を増やすほどpi_estimateは3.14159...に近づくが、
# 有限回の試行では絶対に真の値には到達しない
```

このシミュレーション自体が象徴的です。ランダムな点をどれだけ増やしても、推定値は真の円周率に近づき続けるだけで、有限の手順では決して「ぴったり」にはたどり着けません。

## 8. さらなる疑問

**Q. 円周率は現在何桁まで計算されているのですか？**
スーパーコンピュータを使った計算によって、すでに100兆桁を超える桁数まで求められています。しかし円周率は無理数なので、どれだけ計算を進めても「最後の桁」にたどり着くことは原理的にありません。

**Q. 円周率以外にも有名な無理数はありますか？**
自然対数の底 $e$（ネイピア数、約2.71828...）や、黄金比 $\varphi$（約1.61803...）などが有名です。ちなみに黄金比は無理数ですが、ある2次方程式の解として表せるため、円周率のような「超越数」ではなく「代数的数」に分類されます。

**Q. モンテカルロ法は円周率の計算以外にどう使われていますか？**
金融工学におけるリスク評価や資産価格のシミュレーション、原子力工学での放射線の挙動計算、コンピューターグラフィックスにおける光の反射計算(レイトレーシング)など、直接解くのが難しい複雑な問題を、大量のランダムな試行によって統計的に近似する手法として、幅広い分野で応用されています。

## 9. 数式の完全な導出

4章では「有理数の小数展開は必ず有限小数か循環小数になる」ことと「円周率は無理数である」ことを結論として使いましたが、証明そのものは示していませんでした。ここでは前半をやさしく、後半（円周率が無理数であることの本格的な証明）を大学レベルの微積分を使って完全に導出します。後半は長く高度ですが、一歩ずつ追えるように丁寧に書いています。

### パート1: なぜ有理数の小数展開は必ず循環するのか（やさしい証明）

$p \div q$（$p, q$は正の整数）を筆算の割り算で小数に直す様子を思い出してください。各ステップで得られる余り（あまり）は、必ず

$$0, 1, 2, \ldots, q-1$$

の $q$ 通りのいずれかです（$q$ で割った余りだからです）。

もしどこかのステップで余りが $0$ になれば、そこで割り算は終了し、有限小数になります。

余りが一度も $0$ にならない場合を考えます。割り算を $q+1$ 回行うと、$q+1$ 個の余りが得られますが、余りが取りうる値は $\{0, 1, \ldots, q-1\}$ の $q$ 通りしかありません。部屋が $q$ 個しかないところに $q+1$ 人を入れると、必ずどこかの部屋に2人以上入る（**鳩の巣原理**）のと同じ理屈で、$q+1$ 個の余りの中に**必ず同じ値が2回以上現れます**。

筆算の割り算は「今の余り」だけを見て次の桁と次の余りを機械的に決める手続きです。したがって同じ余りが2回現れたということは、そこから先の桁の並びが、前に同じ余りが出たときとまったく同じパターンで**永遠に繰り返される**ことを意味します。

以上より、有理数の小数展開は必ず「有限小数」か「（あるところから先が）循環する小数」のどちらかになることが証明されました。これは4章で例に挙げた

$$\frac{1}{3} = 0.333\ldots \qquad \frac{1}{7} = 0.142857142857\ldots$$

がそれぞれ1桁・6桁の周期で循環していることとも一致します（$q=3$なら3通り、$q=7$なら7通りの余りしかないため、遅くともその範囲内で循環が始まります）。

### パート2: 円周率が無理数であることの証明（発展）

パート1の結果から、「もし円周率の小数展開が循環しないことを示せれば、円周率は分数で表せない（無理数である）」と言えます。ここでは1947年にアイヴァン・ニーヴンが発表した、微積分を使った比較的短い証明を、省略なく追いかけます。

**背理法の設定：** 円周率が有理数である、すなわち正の整数 $a, b$ を使って $\pi = a/b$ と書けると仮定します。この仮定から矛盾を導きます。

**ステップ1：補助関数を定義する**

正の整数 $n$ を1つ選び（値は後で決めます）、次の多項式を定義します。

$$f(x) = \frac{x^n (a - bx)^n}{n!}$$

これを二項定理で展開すると、$f(x)$ は次数 $n$ から $2n$ までの項だけからなる多項式で、すべての係数が整数を $n!$ で割った形になることがわかります。

**ステップ2：$f$ の各階微分が、$x=0$ で必ず整数になることを示す**

$f(x)$ の最低次の項は $x^n$ なので、$0$ 階から $n-1$ 階までの微分係数は $x=0$ で $0$ になります（低い次数の微分では消えてしまうからです）。

$k \geq n$ については、$x^{n+j}$ の $k$ 階微分（$k=n+j$のとき）が $x=0$ で $k!$ になることを使うと、

$$f^{(k)}(0) = \frac{k!}{n!} \times (\text{整数})$$

の形になります。$k \geq n$ のとき $k!/n! = (n+1)(n+2)\cdots k$ は整数どうしの積なので整数です。したがって、

$$f^{(k)}(0) \text{ は、すべての } k \text{ について整数}$$

**ステップ3：$f$ が $x=\pi/2$ を中心に対称であることを示す**

$\pi = a/b$、すなわち $b\pi = a$ を使うと、

$$(\pi - x)\cdot bx = b\pi x - bx^2 = ax - bx^2 = x(a-bx)$$

という等式が成り立ちます（左辺・右辺とも $ax-bx^2$ に等しくなることを確認してください）。両辺を $n$ 乗して $n!$ で割ると、

$$f(\pi - x) = f(x)$$

が任意の $x$ で成り立つことがわかります。この対称性から、微分についても $f^{(k)}(\pi) = (-1)^k f^{(k)}(0)$ が成り立ち、ステップ2の結果と合わせて、

$$f^{(k)}(\pi) \text{ も、すべての } k \text{ について整数}$$

**ステップ4：偶数階微分の交代和 $F(x)$ を作る**

$$F(x) = f(x) - f''(x) + f^{(4)}(x) - \cdots \pm f^{(2n)}(x)$$

と定義します（$f$ の次数は $2n$ なので、これより高い階の微分は $0$ になり、和は有限項で終わります）。ステップ2・3より、$F(0)$ と $F(\pi)$ はどちらも整数の和なので整数です。

ここで、$F$ の定義を2回微分すると、途中の項がすべて打ち消し合い、

$$F''(x) + F(x) = f(x)$$

というきれいな関係式が得られます（$F''$ を書き出すと $f''-f^{(4)}+f^{(6)}-\cdots$ となり、これに $F=f-f''+f^{(4)}-\cdots$ を足すと、$f$ 以外の項がすべて相殺します）。

**ステップ5：微分の恒等式を作り、積分する**

次の関数を微分してみます。

$$\frac{d}{dx}\Bigl[F'(x)\sin x - F(x)\cos x\Bigr] = F''(x)\sin x + F(x)\sin x = \bigl(F''(x)+F(x)\bigr)\sin x = f(x)\sin x$$

（ステップ4の関係式 $F''+F=f$ を使いました。）これを $0$ から $\pi$ まで積分すると、微積分学の基本定理より、

$$\int_0^{\pi} f(x)\sin x \, dx = \Bigl[F'(x)\sin x - F(x)\cos x\Bigr]_0^{\pi} = F(\pi) + F(0)$$

（$\sin 0 = \sin\pi = 0$、$\cos 0 = 1$、$\cos\pi=-1$ を代入すると、この形になります。）

$F(\pi)$ と $F(0)$ はどちらも整数なので、

$$\int_0^{\pi} f(x)\sin x \, dx \text{ は整数}$$

**ステップ6：この積分が「1以上」であることを示す**

$0 < x < \pi$ の範囲では、$\sin x > 0$ です。また $0<x<\pi=a/b$ の範囲では $x>0$ かつ $a-bx>0$ なので、$f(x) = x^n(a-bx)^n/n! > 0$ です。したがって被積分関数 $f(x)\sin x$ はこの区間で常に正であり、

$$\int_0^{\pi} f(x)\sin x\,dx > 0$$

整数であり、かつ正なので、この積分は**1以上**でなければなりません。

**ステップ7：この積分が「1未満」にもなりうることを示す（矛盾の発生）**

区間 $[0,\pi]$ では $0 \le x \le \pi$ かつ $0 \le a-bx \le a$ なので、$f(x) \le \dfrac{\pi^n a^n}{n!}$ が成り立ちます。$\sin x \le 1$ も使うと、

$$\int_0^{\pi} f(x)\sin x\,dx \le \pi \cdot \frac{(\pi a)^n}{n!} = \frac{\pi^{n+1}a^n}{n!}$$

ここで $n$ を大きくしていくと何が起こるかを考えます。分子 $\pi^{n+1}a^n$ は $n$ に対して指数関数的（掛け算で増える）にしか増えないのに対し、分母の $n!$ は $n$ が大きくなるほど掛け合わせる数自体が増えていくため、はるかに速く増加します。この結果、

$$\frac{\pi^{n+1}a^n}{n!} \longrightarrow 0 \quad (n \to \infty)$$

となることが知られています。したがって、$n$ を十分大きく選べば、この上界を $1$ より小さくできます。

**ステップ8：矛盾の確認と結論**

ステップ6で「積分は1以上の整数」と示し、ステップ7で「$n$を十分大きくとれば積分は1未満」と示しました。しかしステップ1〜6の議論は、どんな正の整数 $n$ を選んでも成り立つ議論です。つまり同じ積分の値が「1以上」でありながら「1未満」でもあるという矛盾が生じます。

矛盾が生じたのは、最初に立てた仮定「$\pi = a/b$（円周率は有理数である）」が誤りだったからです（背理法）。したがって、

**円周率は無理数である。**

以上で証明が完了しました。パート1の結果（有理数は循環小数になる）と合わせると、「円周率の小数展開は循環せず、それゆえ分数でも表せない」という、4章の主張が一切の飛躍なく導かれたことになります。
