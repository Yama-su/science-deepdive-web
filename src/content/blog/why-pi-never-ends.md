## 1. 素朴な疑問

円周率(π)は3.14159265...と、どこまで計算しても割り切れず、規則性もなく数字が続きます。円という身近でシンプルな図形の性質なのに、なぜこんなに複雑な数になるのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「まだ誰も最後まで計算しきれていないだけ」説</li>
    <li><strong>直感2：</strong>「どこかで必ず同じ数字の繰り返しになる」説</li>
    <li><strong>直感3：</strong>「円が完全な図形ではないから」説</li>
  </ul>

実際には、円周率が終わらないことは数学的に**証明されている事実**であり、単に「計算が終わっていない」わけではありません。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    円周率は「分数では絶対に表せない数」であることが証明されています。
    整数÷整数で表せる数（分数）は、必ずどこかで割り切れるか、同じ数字の繰り返しになります。
    円周率はそのどちらにも当てはまらないことがわかっているので、永遠に終わらない、規則性のない数字が続くのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

円周率のように、分数 $\frac{p}{q}$（$p, q$は整数）の形で表せない数を「無理数」と呼びます。円周率が無理数であることは1761年にランベルトによって証明されました。

<div class="math-proof-box">
<div class="proof-header">有理数と無限小数の関係</div>
<div class="proof-body">

分数で表せる数（有理数）を小数で表すと、必ず有限小数になるか、
ある桁以降で同じ数字の並びが無限に繰り返される循環小数になる。

$$\frac{1}{3} = 0.333\ldots \quad \frac{1}{7} = 0.142857142857\ldots$$

円周率 $\pi$ はこのどちらにも当てはまらない（非循環無限小数）ことが証明されているため、
分数では表せない無理数である。

</div>
</div>

さらに円周率は「超越数」でもあることが1882年にリンデマンによって証明されています。これは、円周率がどんな有理数係数の代数方程式の解にもならないという、無理数よりもさらに強い性質です。この事実は「与えられた円と同じ面積の正方形を、定規とコンパスだけで作図できるか」という古代からの難問（円積問題）が**不可能である**ことの証明にもつながりました。

## 5. 数値シミュレーション

円周率は「モンテカルロ法」というランダムな試行を使った方法でも近似的に求めることができます。正方形の中にランダムな点を大量に打ち、その点が内接する円の中に入る割合から円周率を推定します。

![モンテカルロ法による円周率の近似シミュレーション](/assets/simulations/pi_monte_carlo.png)
*図1: 左は正方形内にランダムに打った点(円の内側/外側で色分け)、右は点の数を増やすほど推定値が3.14159...に近づいていく様子*

左図は一辺2の正方形の中にランダムな点を3000個打ち、中心から半径1の円の内側に入った点を青、外側に落ちた点をオレンジで塗り分けたものです。正方形の面積は4、円の面積は $\pi$ なので、円の中に入った点の割合はおおよそ $\pi / 4$ に近づくはずです。この割合を4倍すれば円周率の近似値が得られます。右図はこの考え方に基づき、点の数を10個から3000個まで対数目盛りで増やしていったときの推定値の変化を示しています。点が少ないうちは赤い破線（真の $\pi$ の値）から大きくずれていますが、点数が増えるにつれて徐々に真の値へと近づいていく様子がわかります。ただし、これはあくまで統計的な近似であり、円周率の桁を厳密に求める方法ではありません。

```python
import numpy as np

rng = np.random.default_rng(42)
x = rng.uniform(-1, 1, 3000)
y = rng.uniform(-1, 1, 3000)
inside = x**2 + y**2 <= 1

pi_estimate = 4 * np.mean(inside)
# 点の数を増やすほどpi_estimateは3.14159...に近づくが、
# 有限回の試行では絶対に真の値には到達しない
```

このシミュレーション自体が象徴的です。ランダムな点をどれだけ増やしても、推定値は真の円周率に近づき続けるだけで、有限の手順では決して「ぴったり」にはたどり着けません。

## 7. よくある発想は何が間違っていたのか

<div class="callout callout-intuition">
  <div class="callout-title">3大直感を検証する</div>
  <ul>
    <li><strong>「まだ計算しきれていないだけ」説の誤り：</strong>円周率が無理数であることは、1761年にランベルトによって数学的に証明された事実です。これはコンピュータの計算能力がどれだけ向上しても、原理的に「終わることがあり得ない」ことが証明済みだという意味で、単なる計算の進捗の問題ではありません。</li>
    <li><strong>「どこかで繰り返しになる」説の誤り：</strong>循環小数になる数は必ず分数で表せることが数学的に証明されていますが、円周率は分数で表せない（無理数である）ことも証明されています。したがって円周率が循環小数になることは論理的にあり得ません。</li>
    <li><strong>「円が完全な図形ではない」説の誤り：</strong>円は数学的に一切の曖昧さなく定義された図形です。円周率が無理数になるのは図形の不完全さのせいではなく、「円周と直径の比」という量そのものが持つ性質によるものです。</li>
  </ul>

## 8. さらなる疑問

**Q. 円周率は現在何桁まで計算されているのですか？**
スーパーコンピュータを使った計算によって、すでに100兆桁を超える桁数まで求められています。しかし円周率は無理数なので、どれだけ計算を進めても「最後の桁」にたどり着くことは原理的にありません。

**Q. 円周率以外にも有名な無理数はありますか？**
自然対数の底 $e$（ネイピア数、約2.71828...）や、黄金比 $\varphi$（約1.61803...）などが有名です。ちなみに黄金比は無理数ですが、ある2次方程式の解として表せるため、円周率のような「超越数」ではなく「代数的数」に分類されます。

**Q. モンテカルロ法は円周率の計算以外にどう使われていますか？**
金融工学におけるリスク評価や資産価格のシミュレーション、原子力工学での放射線の挙動計算、コンピューターグラフィックスにおける光の反射計算(レイトレーシング)など、直接解くのが難しい複雑な問題を、大量のランダムな試行によって統計的に近似する手法として、幅広い分野で応用されています。
