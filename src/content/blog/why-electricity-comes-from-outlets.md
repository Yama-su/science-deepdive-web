## 1. 素朴な疑問

コンセントにプラグを差し込むと、いつでも電気製品が動きます。コンセントの中には、電池のように電気があらかじめ蓄えられているのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「コンセントの中や電線の中に、電気がぎっしり蓄えられている」説</li>
    <li><strong>直感2：</strong>「発電所で作られた電気の『粒』が、電線の中を光の速さで一直線に流れてきて届く」説</li>
    <li><strong>直感3：</strong>「電気はどこかで自然に湧いてくるもので、使うとなくなっていく燃料のようなもの」説</li>
  </ul>
</div>

実際には、コンセントに電気が「貯蔵」されているわけではありません。発電所で今まさに作られている電気エネルギーが、電線を通じてリアルタイムで送られてきているのです。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    発電所では、水の流れや蒸気の力で大きな磁石をぐるぐる回しています。
    磁石をコイル（導線をぐるぐる巻いたもの）の近くで回転させると、
    コイルに電気を流そうとする力（電圧）が生まれます。
    この「今まさに発電機が回っている」ことによって生まれる電気が、電線を通ってそのままコンセントに届いているのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

発電の基本原理は「電磁誘導」と呼ばれる現象で、19世紀にファラデーが発見した法則で説明されます。

<div class="math-proof-box">
<div class="proof-header">ファラデーの電磁誘導の法則</div>
<div class="proof-body">

コイルを貫く磁束（磁場の量）$\Phi$ が時間とともに変化すると、コイルに起電力（電圧）$\varepsilon$ が生じる。

$$\varepsilon = -\frac{d\Phi}{dt}$$

発電機では、磁石（または磁場）の中でコイルを一定の速さで回転させる。
コイルが磁場の向きとなす角度が時間とともに変わるため、磁束 $\Phi$ は、

$$\Phi(t) = BA\cos(\omega t)$$

（$B$: 磁束密度、$A$: コイルの面積、$\omega$: 回転の角速度）という形で周期的に変化し、
これを時間で微分すると、正弦波状に変化する起電力が生まれる。

</div>
</div>

つまり家庭に届く電気（家庭用電源）は、発電所のタービンが「今この瞬間も」回転し続けることによって、リアルタイムで生成されているエネルギーです。回転を止めれば、その瞬間から電気は流れなくなります。コンセントは電気を貯めておく倉庫ではなく、発電所とあなたの家を結ぶ「電線という水道管」のような役割を果たしているのです。

## 5. 数値シミュレーション

回転するコイルの磁束の変化と、そこから生まれる電圧（起電力）の波形をシミュレーションしました。

![回転するコイルの磁束と、それによって生じる正弦波状の電圧の波形](/assets/simulations/ac_induction_waveform.png)
*図1: 上段は磁束の変化、下段はそこから生まれる正弦波状の電圧（交流電源の波形）*

上のグラフは、コイルが回転するにつれて磁束がなめらかに周期的に変化する様子を示しています。下のグラフは、この磁束の変化を時間で微分することで得られる、電圧（起電力）の波形です。磁束が最大・最小になる瞬間（変化率がゼロの瞬間）には電圧はゼロになり、逆に磁束が最も急激に変化している瞬間に電圧が最大になっています。この正弦波の形こそが、私たちが「交流（AC）電源」と呼んでいる家庭用電気の実際の波形です。日本の家庭用電源は、東日本で1秒間に50回、西日本で60回、この波形を繰り返しています。

```python
import numpy as np

B = 1.0    # 磁束密度
A = 1.0    # コイルの面積
f = 60     # Hz(発電機の回転数)
omega = 2 * np.pi * f

t = np.linspace(0, 3/f, 500)
flux = B * A * np.cos(omega * t)
emf = B * A * omega * np.sin(omega * t)  # -d(flux)/dt
```

## 7. よくある発想は何が間違っていたのか

<div class="callout callout-intuition">
  <div class="callout-title">3大直感を検証する</div>
  <ul>
    <li><strong>「コンセントの中に電気が蓄えられている」説の誤り：</strong>コンセントや電線自体は、電気を貯蔵する能力をほとんど持ちません（電池やコンデンサとは違います）。4章で見た通り、電気は発電所での「今まさに起きている」電磁誘導によって、リアルタイムに供給され続けています。</li>
    <li><strong>「電気の粒が光速で一直線に流れてくる」説の誤り：</strong>実は、導線の中を実際に移動する電子自体の速さ（ドリフト速度）は、驚くほど遅く、1秒間に数ミリメートル程度に過ぎません。電気のスイッチを入れた瞬間に明かりがつくのは、電子そのものが高速で移動してくるからではなく、導線内の電場（電気的な力の作用）が光速に近い速さで伝わり、導線中のすべての電子がほぼ同時に一斉に動き始めるためです。</li>
    <li><strong>「電気は燃料のように使うとなくなる」説の誤り：</strong>電気は物質ではなくエネルギーの一形態であり、消費されて「なくなる」というより、電気エネルギーが光や熱、運動エネルギーなど、別の形のエネルギーに変換されているだけです。エネルギー保存則により、エネルギーの総量自体は失われていません。</li>
  </ul>
</div>

## 8. さらなる疑問

**Q. なぜ家庭用電源は直流(DC)ではなく交流(AC)なのですか？**
4章で見た通り、回転する発電機から自然に生み出される電気は、そもそも正弦波状の交流です。また交流は変圧器を使って電圧を簡単に変換できるため、発電所から家庭までの長距離送電で、電力損失を抑えるために高電圧で送り、家庭に近づくにつれて安全な電圧まで下げる、という効率的な運用がしやすいという利点もあります。

**Q. 停電すると、なぜ電気がすぐに使えなくなるのですか？**
4章で説明した通り、家庭に届く電気は貯蔵されたものではなく、発電所での発電が継続していることが前提の、リアルタイムのエネルギー供給です。発電所や送電網に何らかのトラブルが起きて電力の供給が止まると、貯蔵された予備がないため、即座に電気が使えなくなります。これが、蓄電池（バッテリー）を持つ機器だけが停電時にも動き続けられる理由です。

**Q. 太陽光発電やスマートフォンの充電も、同じ電磁誘導の原理ですか？**
いいえ、少し異なります。太陽光発電は「光電効果」という、光のエネルギーが半導体内の電子を直接動かす、別の物理現象を利用しています。一方、多くのワイヤレス充電器は、まさに本記事で解説した電磁誘導の原理（変動する磁場がコイルに電流を誘導する）を応用した技術です。

## 9. 数式の完全な導出

4章で示した磁束の式 $\Phi(t)=BA\cos(\omega t)$ と、そこから生まれる起電力の式を、磁束の定義から一切の飛躍なく導出します。

### ステップ1: 磁束の定義を確認する

磁束 $\Phi$ とは、コイルの面を貫く磁場の量を表す量で、磁束密度 $B$、コイルの面積 $A$、そして磁場の向きとコイルの面の法線（垂直方向）とのなす角度 $\theta$ を使って、

$$\Phi = BA\cos\theta$$

と定義されます。コイルの面が磁場に対して垂直（$\theta=0$）のとき磁束は最大になり、平行（$\theta=90°$）のとき磁束はゼロになります。

### ステップ2: コイルが一定の速さで回転するとする

発電機の中でコイルが、角速度 $\omega$（1秒あたりに回転する角度）で回転しているとすると、時刻 $t$ における角度は、

$$\theta(t) = \omega t$$

（$t=0$ でコイルが磁場に垂直な向きにあると仮定します。）

### ステップ3: 磁束を時間の関数として表す

ステップ1の式にステップ2の関係を代入すると、

$$\Phi(t) = BA\cos(\omega t)$$

これが4章で示した磁束の式です。

### ステップ4: ファラデーの法則を適用し、起電力を求める

ファラデーの法則 $\varepsilon = -d\Phi/dt$ に、ステップ3の結果を代入します。三角関数の微分公式 $\dfrac{d}{dt}\cos(\omega t) = -\omega\sin(\omega t)$ を使うと、

$$\varepsilon(t) = -\frac{d}{dt}\bigl[BA\cos(\omega t)\bigr] = -BA\times(-\omega\sin(\omega t)) = BA\omega\sin(\omega t)$$

### 結論

得られた式 $\varepsilon(t) = BA\omega\sin(\omega t)$ は、時間とともに正弦波状に変化する電圧を表しています。この導出でわかる重要な点は、家庭用電源が「正弦波（サインカーブ）」という特定の形をしている理由が、偶然でも人為的な設計でもなく、「コイルが一定の速さで回転する」という物理的な動作と、磁束の定義、そしてファラデーの法則という3つの要素を組み合わせるだけで、数式の上で必然的に導かれる結果だという点です。発電機の回転数（$\omega$、日本では50Hzまたは60Hzに対応）が、そのまま家庭に届く電気の周波数を決めているのです。
