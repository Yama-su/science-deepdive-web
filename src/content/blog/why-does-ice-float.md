## 1. 素朴な疑問

コップに氷を入れると必ず水に浮きます。当たり前の光景ですが、実はほとんどの物質は「固体の方が液体より重い（密度が高い）」ため沈みます。水はなぜ逆なのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「氷の中に空気が入っているから軽い」説</li>
    <li><strong>直感2：</strong>「凍ると体積が減って軽くなる」説</li>
    <li><strong>直感3：</strong>「水はどんな物質でも固体が軽いのが普通」説</li>
  </ul>
</div>

実際には氷に特別な空気は入っておらず、むしろ凍ると体積が**増える**ことが原因です。そしてこれは水に特有の珍しい性質です。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    水の分子は凍って氷になるとき、規則正しい網目状に並びます。
    この並び方はすき間が多く、同じ重さの水よりも体積が大きくなります。
    体積が大きい（すかすか）ということは、同じ体積で比べると氷の方が軽い、つまり浮くのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

水分子（H₂O）は、酸素原子と2つの水素原子の間に「水素結合」という比較的強い分子間力を持ちます。液体の水では水分子が比較的自由に動き回り、分子同士が密に詰まっています。

しかし温度が下がって氷になると、水分子は水素結合によって**正四面体構造**を基本とした規則正しい結晶格子（六方晶系）を形成します。この結晶構造は、液体状態よりもすき間の多い、比較的疎な配置になるため、同じ質量の水よりも体積が大きくなり、結果として密度が低くなります。

さらに液体の水そのものにも面白い性質があり、0℃から温度を上げていくと、約4℃まではむしろ密度が増加し、4℃を超えると通常の物質と同様に温度上昇とともに密度が減少していきます（密度異常）。これも水分子間の水素結合ネットワークが温度によって組み変わることに起因します。

## 5. 数値シミュレーション

水の密度が温度によってどう変化するかをグラフにしました。氷の密度(約917 kg/m³)は、どの温度の液体の水よりも低いことがわかります。

![水の密度と温度の関係、4°C付近で密度が最大になり氷はそれより軽い](/assets/simulations/ice_float_density.png)
*図1: 液体の水は約4°Cで密度が最大になり、氷(点線)はそれよりずっと軽い*

グラフの実線は液体の水の密度を0℃から100℃まで計算した曲線で、山なりになっていることに注目してください。0℃から温度が上がるにつれて密度はいったん**上昇**し、約4℃でピークを迎えたあと、他の物質と同様に温度上昇とともに**下降**していきます。この「4℃で最大」という凸型のグラフ自体が、水が持つ密度異常を端的に示しています。一方で点線で示した氷(0℃)の密度は、グラフに描かれたどの温度の液体の水よりも低い位置にあり、両者が絶対に交わらないことが「氷は必ず水に浮く」ことの視覚的な裏付けになっています。

このグラフは、Kellの実験式(水の密度を温度の関数として近似する経験式)を用いて生成しました。

```python
import numpy as np

t = np.linspace(0, 100, 500)
density = (
    999.83952 + 16.945176 * t - 7.9870401e-3 * t**2
    - 46.170461e-6 * t**3 + 105.56302e-9 * t**4
    - 280.54253e-12 * t**5
) / (1 + 16.879850e-3 * t)
```

## 7. よくある発想は何が間違っていたのか

<div class="callout callout-intuition">
  <div class="callout-title">3大直感を検証する</div>
  <ul>
    <li><strong>「空気が入っている」説の誤り：</strong>気泡を極力取り除いた純粋な水を凍らせる実験でも、氷は変わらず水に浮きます。結晶構造から理論的に計算した密度も実測値とほぼ一致するため、空気の混入は本質的な原因ではありません。</li>
    <li><strong>「体積が減る」説の誤り：</strong>実際には逆で、水が氷になると体積は約9%も**増加**します。冬に水道管が凍って破裂する事故は、この体積膨張が原因です。</li>
    <li><strong>「水は特別ではない」説の誤り：</strong>鉄・ろう・ドライアイス(固体のCO₂)など、ほとんどの物質は固体の方が液体より密度が高く、沈みます。水はこの点でかなり珍しい例外なのです。</li>
  </ul>
</div>

## 8. さらなる疑問

**Q. 深い湖や海はなぜ水面からではなく、全体が一気に凍らないのですか？**
「4℃で密度最大」という性質が、実は湖を守っています。水面が冷えて4℃より冷たくなると、その水はむしろ軽くなるため沈まずに表面にとどまり、氷になります。一方、湖の底には密度が最大の4℃の水が沈んだまま留まるため、湖全体が凍りつくことはなく、氷の下で魚などの生態系が冬を越せるのです。

**Q. 水以外にも「固体の方が軽い」物質はありますか？**
数は少ないですが存在します。代表的なのはビスマス、ケイ素、ガリウム、ゲルマニウムなどで、これらも凝固時に体積が膨張する性質を持ちます。地球上でありふれた液体である水がこの性質を持つことは、生命にとって非常に幸運な偶然だったと考えられています。

**Q. 氷にはIh氷(普通の氷)以外の種類もあるのですか？**
あります。高い圧力をかけると、水分子はIh氷とは異なる結晶構造をとり、氷II、氷III…氷XVIなど、性質の異なる複数の「氷の多形」が存在することが実験的に確認されています。中には通常の氷よりも密度が高いものもあり、木星の衛星のような高圧環境の天体内部に存在すると考えられています。
