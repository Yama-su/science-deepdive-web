## 1. 素朴な疑問

鍋で牛乳を温めていると、表面に薄い膜が張ります。牛乳全体がとろりと固まっているわけではないのに、なぜ表面にだけ、この膜ができるのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「膜は牛乳の脂肪分がただ固まって浮いてきたもの」説</li>
    <li><strong>直感2：</strong>「膜はホコリなど、外から入り込んだ異物が浮いているだけ」説</li>
    <li><strong>直感3：</strong>「膜ができるのは、牛乳が傷み始めているサイン」説</li>
  </ul>
</div>

実際には、膜の正体は主にタンパク質（カゼインや乳清タンパク質）であり、表面での水分の蒸発と、熱によるタンパク質の変性が組み合わさって生じる現象です。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    牛乳を温めると、表面からだけ水分が蒸発していきます。
    水は蒸発してなくなりますが、水に溶けていたタンパク質は蒸発せずにその場に残るので、
    表面のタンパク質の濃さがどんどん濃くなっていきます。
    濃くなったタンパク質は熱でその形を変え（変性し）、絡み合って薄い膜を作るのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

膜ができる根本的な原因は、表面という特定の場所だけで起こる「濃縮」という現象です。これは質量保存の法則から、定量的に説明できます。

<div class="math-proof-box">
<div class="proof-header">蒸発による表面のタンパク質濃度の上昇</div>
<div class="proof-body">

牛乳の表面付近にある薄い層（体積 $V_0$）に含まれるタンパク質の質量 $m$ は、蒸発が起きても変化しない
（タンパク質は水のように気体になって逃げていかない）。

水分が蒸発して、この層の体積が $V_0$ から $V_0(1-f)$ に減った場合
（$f$: 蒸発した水分の体積の割合、$0<f<1$）、
タンパク質の濃度 $C$ は、

$$C = \frac{m}{V_0(1-f)} = \frac{C_0}{1-f}$$

（$C_0=m/V_0$: 蒸発前の元の濃度）と表される。

</div>
</div>

この式が示す重要な点は、蒸発が進む（$f$ が1に近づく）につれて、濃度 $C$ が際限なく大きくなっていくということです。牛乳の内部（バルク）では、対流によって全体が混ざり合うため、このような極端な濃縮は起こりません。しかし表面という、蒸発が直接起こる薄い層だけは、タンパク質のような大きな分子がすぐには拡散して薄まることができず、局所的に急激な濃縮が進みます。この濃縮されたタンパク質が、加熱による変性（熱で立体構造がほどけること、別記事「卵はなぜ焼くと固まるのか」で解説した現象と同じ原理）を起こし、絡み合って薄い膜を形成するのです。

## 5. 数値シミュレーション

表面の水分が蒸発する割合に対して、タンパク質濃度がどう変化するかをシミュレーションしました。

![蒸発した水分の割合に対するタンパク質濃度の上昇を示すグラフ](/assets/simulations/milk_skin_concentration.png)
*図1: 蒸発が進むにつれて、表面のタンパク質濃度は急激に上昇していく*

グラフは、蒸発した水分の割合（横軸）が大きくなるにつれて、タンパク質の濃度（縦軸、元の濃度に対する倍率）が、なだらかな増加から急激な増加へと変化していく様子を示しています。赤い破線で示した「変性が起こる濃度の目安」に達すると、そこでタンパク質が凝集を始め、目に見える膜として現れます。牛乳の表面は、鍋全体の中でもこの蒸発が集中的に起こる唯一の場所であるため、膜がまさに表面にだけ形成されるのです。

```python
import numpy as np

f = np.linspace(0, 0.95, 300)  # 蒸発した水分の割合
C_ratio = 1 / (1 - f)  # 元の濃度に対する倍率
# fが1に近づくとC_ratioは急激に大きくなる
```

## 8. さらなる疑問

**Q. 膜ができるのを防ぐには、どうすればよいですか？**
かき混ぜながら加熱する、鍋にフタをする（蒸発そのものを抑える）、加熱後に表面に少量のバターや油の層を作る（水分の蒸発を物理的に遮断する）などの方法が、実際の調理でよく使われます。これらはいずれも、4章の式における「蒸発の割合 $f$」を抑えることで、表面の急激な濃縮を防ぐ効果を持っています。

**Q. 豆乳を温めても、同じように膜ができますか？**
はい、豆乳を加熱すると、大豆由来のタンパク質が同じ原理で表面に膜を作ります。これは「湯葉（ゆば）」として、日本料理では古くから食材として活用されています。膜の形成という物理現象を、逆に積極的に利用した例といえます。

**Q. 電子レンジで牛乳を温めても、同じように膜はできますか？**
できにくいことが知られています。電子レンジは液体全体を内部から比較的均一に加熱するため、鍋でじっくり加熱する場合に比べて、表面だけが選択的に高温になり水分が集中的に蒸発するという状況が起こりにくいためです。4章のモデルで言えば、表面と内部の温度差が小さいために、局所的な濃縮が進みにくいと考えられます。

## 9. 数式の完全な導出

4章で示した式 $C=C_0/(1-f)$ を、質量保存則から一切の飛躍なく導出します。

### ステップ1: タンパク質の質量が保存されることを確認する

牛乳の表面付近にある、体積 $V_0$ の薄い層を考えます。この層に含まれるタンパク質の初期質量を $m$ とすると、初期濃度は、

$$C_0 = \frac{m}{V_0}$$

加熱によって水分は蒸発しますが、タンパク質分子は（沸騰するほどの高温にならない限り）気体になって蒸発することはありません。したがって、この層に含まれるタンパク質の質量 $m$ は、時間が経っても変化しません。

### ステップ2: 蒸発による体積の変化を式にする

蒸発した水分の体積の割合を $f$（$0<f<1$）とすると、層全体の体積は、元の体積から蒸発した分だけ減少します。

$$V = V_0 - f V_0 = V_0(1-f)$$

（$f=0$ のとき蒸発なしで $V=V_0$、$f=1$ のとき水分がすべて蒸発して体積がほぼゼロに近づくことに対応します。実際には $f=1$ に達する前に、他の固形成分により体積の減少には限界がありますが、ここでは理想化したモデルを考えます。）

### ステップ3: 濃度の定義に代入する

濃度は「質量 ÷ 体積」で定義されるので、蒸発後の濃度 $C$ は、

$$C = \frac{m}{V} = \frac{m}{V_0(1-f)}$$

### ステップ4: 初期濃度を使って整理する

ステップ1の $C_0=m/V_0$ より $m=C_0V_0$ なので、これを代入すると、

$$C = \frac{C_0V_0}{V_0(1-f)} = \frac{C_0}{1-f}$$

### 結論

これが4章で示した式です。この導出は、質量保存則という、化学の中でも最も基本的な法則を、蒸発という具体的な現象に当てはめただけの、シンプルな代数計算です。それでも、$f$ が1に近づくにつれて濃度 $C$ が発散していくという、直感的には見えにくい急激な濃縮効果を、明確な数式として示してくれます。牛乳の表面という、目には見えないミクロな場所で、この式が示す通りの劇的な濃縮が実際に進行し、その結果として私たちの目に見える「膜」という現象が生まれているのです。
