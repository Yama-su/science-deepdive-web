## 1. 素朴な疑問

指を1本立てて、もう1本立てれば、合わせて2本になります。「1+1=2」はあまりに当たり前で、証明する必要すらないように思えます。しかし、これを厳密に証明しようとすると、何を根拠にすればよいのでしょうか。

実際には「1+1=2」は数学の中で厳密に証明できる定理であり、指やリンゴを並べる行為は「証明」ではなく「具体例による確認」に過ぎません。そして300ページという話も、実話です。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    数を「0、その次、その次の次…」と順番に作っていくルールを決めます。
    「1」は「0の次」、「2」は「1の次」と決めます。
    足し算の「1に1を足す」というのは、「1の次の数を答える」というルールで定義すると、
    「1の次」はまさに「2」だと決めた数そのものなので、1+1は2になるのです。
  </p>

## 4. わかりやすく厳密な答え

19世紀の数学者ジュゼッペ・ペアノは、自然数を定義するための、わずかな数の基本ルール（公理）を提案しました。

<div class="math-proof-box">
<div class="proof-header">ペアノの公理(抜粋)と1+1=2の証明</div>
<div class="proof-body">

**ペアノの公理（必要な部分のみ）：**
$0$ は自然数である。すべての自然数 $n$ には、「次の数（後続数）」$S(n)$ が存在する。

**数の定義：** $1 := S(0)$（1とは0の次の数）、$2 := S(1) = S(S(0))$（2とは1の次の数）と定義する。

**足し算の再帰的定義：** $a + 0 = a$、および $a + S(b) = S(a+b)$ と定義する。

**証明：** $1+1$ を計算する。$1 = S(0)$ であることを使い、$1+1$ を $1+S(0)$ と書き直す。
足し算の定義（$a+S(b)=S(a+b)$、ここで $a=1, b=0$）を適用すると、

$$1+1 = 1+S(0) = S(1+0)$$

足し算の定義（$a+0=a$）より $1+0=1$ なので、

$$S(1+0) = S(1)$$

$S(1)$ は、まさに2の定義そのものなので、

$$1+1 = S(1) = 2$$

</div>
</div>

この証明の重要なポイントは、「2」という数自体が、あらかじめ「1の次の数」として定義されているという点です。そして足し算の規則も「1を足すとは、次の数に進むこと」として定義されています。この2つの定義を組み合わせるだけで、「1+1=2」は当たり前の事実としてではなく、論理的に導出される定理として証明されるのです。

## 5. 数値シミュレーション

ペアノの公理に基づく再帰的な足し算の定義が、通常の足し算と本当に一致するのかを、コンピュータで検証しました。

![ペアノの再帰的な足し算と通常の足し算の結果を比較した散布図、すべて完全一致](/assets/simulations/peano_addition_check.png)
*図1: 150組のランダムな数の組について、再帰的な定義による計算結果と、通常の足し算の結果を比較*

グラフの横軸は、プログラミング言語に標準搭載された通常の足し算（+演算子）で計算した結果、縦軸は「$a+0=a$」「$a+S(b)=S(a+b)$」という2つのルールだけを使い、再帰的に（1ずつ数えながら）計算した結果です。150組のまったく異なる数の組み合わせについて計算しましたが、すべての点が誤差ゼロで対角線上に一致しています。これは、私たちが日常使っている「＋」という記号が計算していることと、ペアノの公理から再帰的に定義した足し算が、完全に同じ結果を返すことを示しています。

```python
def succ(n):
    return n + 1

def peano_add(a, b):
    if b == 0:
        return a
    return succ(peano_add(a, b - 1))
    # b回だけ「次の数」に進む操作を繰り返しているだけ

# peano_add(a, b) は、常にネイティブの a + b と完全に一致する
```

## 8. さらなる疑問

**Q. なぜラッセルたちは、ペアノの公理をそのまま使わずに、わざわざ300ページもかけて再構築したのですか？**
ラッセルとホワイトヘッドの目標は、ペアノの公理そのものが正しいことを含め、数学全体を、より基礎的な「論理」だけから証明することでした。ペアノの公理を単に「前提として認める」のではなく、その公理自体がなぜ成り立つべきなのかを、純粋な論理学の言葉で基礎づけようとしたため、膨大なページ数が必要になったのです。

**Q. ペアノの公理を使わずに、数を定義する別の方法はあるのですか？**
あります。集合論の枠組みでは、フォン・ノイマンによる自然数の構成法が有名です。$0$ を空集合 $\emptyset$、$1$ を $\{\emptyset\}$、$2$ を $\{\emptyset, \{\emptyset\}\}$ というように、集合を入れ子にすることで自然数を定義する方法があり、これはラッセルたちの目標に近い、より集合論的なアプローチです。

**Q. 「1+1=2」が成り立たない数学の世界はあるのですか？**
はい、興味深いことにあります。例えば「ブール代数」という体系（コンピュータの論理回路の基礎）では、$1+1=1$ と定義されることがあります（論理和のOR演算として）。また $\mathbb{Z}/2\mathbb{Z}$（2を法とする整数、mod 2の世界）では、$1+1=0$ になります。これらは「+」という記号に、通常の足し算とは異なる規則を割り当てた、別の数学的体系です。日常の「1+1=2」は、あくまで私たちが普段使っている自然数の体系における結論です。

## 9. 数式の完全な導出

4章の証明では「$a+0=a$」「$a+S(b)=S(a+b)$」という足し算の再帰的定義を天下り的に使いましたが、なぜこの定義の仕方で「足し算」と呼べるものが正しく定義できるのか、その論理を確認します。

### ステップ1: なぜ「再帰的定義」で足し算全体が定義できるのか

$a+b$ を計算したいとき、$b$ が $0$ なら定義の1行目（$a+0=a$）で即座に答えが出ます。$b$ が $0$ でなければ、ペアノの公理により $b$ は必ず何らかの数 $c$ の後続数として $b=S(c)$ の形で書けます（これは「$0$ 以外の自然数はすべて、ある数の次の数である」という、ペアノの公理のもう1つの重要な帰結です）。このとき定義の2行目を使うと、

$$a + b = a + S(c) = S(a+c)$$

となり、「$a+b$ を計算する」という問題が、「$a+c$（$b$ よりも1つ手前の数との足し算）を計算する」という、一段階簡単な問題に置き換わります。

### ステップ2: この置き換えを繰り返すと、必ず終わる

ステップ1の置き換えを繰り返すと、2番目の数（最初は $b$）は $c, \ldots$ と1つずつ小さくなっていき、有限回の操作で必ず $0$ に到達します（自然数は無限に小さくなり続けることはできないためです）。$0$ に到達した時点で定義の1行目が使え、そこから $S(\ )$ を必要な回数だけ「巻き戻す」ことで、最終的な答えが確定します。

### ステップ3: 具体的に $1+1$ でこの手順を追う

$1+1$ を計算します。$1=S(0)$ なので、$b=1=S(0)$ の形（ステップ1の $c=0$ に対応）に当てはめると、

$$1+1 = 1+S(0) = S(1+0)$$

ここで $1+0$ は定義の1行目からすぐに $1$ とわかるので（$b=0$ に到達した）、

$$S(1+0) = S(1)$$

そして $S(1)$ は4章で確認した通り、まさに「2」の定義そのものです。

### 結論

この一連の手順が示しているのは、「$a+b$」という計算が、突然答えが天下りで与えられるものではなく、「$b$ を $1$ 減らしながら、$S(\ )$（次の数に進む操作）を積み重ねていく」という、有限回で必ず終わる機械的な手続きとして、完全に定義し尽くされているということです。$1+1=2$ という結論は、この手続きを $1+1$ という最も単純なケースに当てはめた、避けようのない帰結なのです。
