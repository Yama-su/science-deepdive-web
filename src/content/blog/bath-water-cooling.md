## 1. 素朴な疑問

沸かしたばかりの熱いお風呂は、最初のうちはあっという間に温度が下がっていきますが、ぬるくなってくると、そこから先はなかなか冷めなくなります。この「冷め方のペース」の変化には、どんな理由があるのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「お湯は時間とともに、いつも同じペースで冷めていく」説（直線的に冷める）</li>
    <li><strong>直感2：</strong>「最初は熱いから速く冷め、その後はなんとなくゆっくりになる」説（理由は不明）</li>
    <li><strong>直感3：</strong>「室温は関係なく、お湯の温度だけで冷め方が決まる」説</li>
  </ul>
</div>

実際には、冷める速さは「お湯と室温の温度差」によって決まるという、明確な法則があります。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    お湯が冷める速さは、お湯と部屋の温度の「差」が大きいほど速くなります。
    沸かしたてのお湯は部屋との温度差が大きいので、どんどん冷めます。
    でも冷めて部屋の温度に近づくと、温度差が小さくなるので、冷めるスピードもゆっくりになっていくのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

この現象は「ニュートンの冷却法則」として知られています。

<div class="math-proof-box">
<div class="proof-header">ニュートンの冷却法則</div>
<div class="proof-body">

温度 $T$ の物体が、温度 $T_{\text{env}}$ の環境（室内）に置かれているとき、
温度が変化する速さ（時間あたりの温度変化）は、物体と環境の温度差に比例する。

$$\frac{dT}{dt} = -k(T - T_{\text{env}})$$

（$k$ は正の定数で、お湯の量や容器の材質などによって決まる冷却の起こりやすさを表す）

この式（微分方程式）を解くと、

$$T(t) = T_{\text{env}} + (T_0 - T_{\text{env}})e^{-kt}$$

（$T_0$: 時刻0での初期温度）という、指数関数的に減少する式が得られる。

</div>
</div>

この式が意味するのは、お湯の温度は室温に向かって「直線的」にではなく「指数関数的」に近づいていくということです。温度差 $T-T_{\text{env}}$ が大きい最初のうちは冷える速さ $dT/dt$ も大きく（式の右辺が大きな負の値）、お湯が室温に近づくにつれて温度差が縮まり、冷える速さもどんどん小さくなっていきます。この式の完全な導出過程は、9章で微分方程式を解く手順とともに示します。

## 5. 数値シミュレーション

初期温度40℃のお湯が、室温20℃の部屋で時間とともにどう冷めていくかをシミュレーションしました。

![お風呂の水温が時間とともに指数関数的に低下するグラフ](/assets/simulations/bath_cooling_curve.png)
*図1: 最初の10分間の温度低下幅と、60〜70分の間の温度低下幅を比較すると、明らかに前者の方が大きい*

グラフの曲線は、最初は急な下り坂で始まり、時間が経つにつれてだんだん傾きが緩やかになる、典型的な指数関数のカーブを描いています。グラフに書き込んだ通り、最初の10分間での温度低下幅は、60分から70分にかけての10分間での低下幅よりもはるかに大きくなっています。これはお湯の温度が室温（グラフの点線）に近づくにつれて、4章で示した式の温度差の項 $(T-T_{\text{env}})$ が小さくなり、冷める速さそのものが遅くなっていくためです。

```python
import numpy as np

T0 = 40.0     # 初期温度
T_env = 20.0  # 室温
k = 0.05      # 冷却係数

t = np.linspace(0, 90, 300)
T = T_env + (T0 - T_env) * np.exp(-k * t)
```

## 8. さらなる疑問

**Q. お湯が完全に室温と同じ温度になることはあるのですか？**
4章の式 $T(t) = T_{\text{env}} + (T_0-T_{\text{env}})e^{-kt}$ を見ると、$e^{-kt}$ は $t$ がどれだけ大きくなっても理論上は正確に0にはならず、限りなく0に近づき続けるだけです。つまり数学的には、お湯は室温に限りなく近づきますが、無限の時間をかけても厳密には一致しません。ただし実用上は、数時間もあれば見分けがつかないほど室温に近づきます。

**Q. 保温性の高い浴槽と、そうでない浴槽とでは、何が違うのですか？**
4章の式の冷却係数 $k$ の大きさが違います。断熱性の高い浴槽は熱が外部に逃げにくいため $k$ が小さく、指数関数の減少がゆるやかになります。保温浴槽が「お湯が冷めにくい」と言われるのは、この $k$ を小さくする工夫（断熱材やフタなど）が施されているためです。

**Q. 冷たい飲み物が部屋の温度でだんだん温まっていく現象も、同じ法則で説明できますか？**
はい、まったく同じ法則が使えます。$T_0$ が室温より低い場合、式の $(T_0-T_{\text{env}})$ の部分が負の値になり、時間とともに $T(t)$ は室温に向かって「上昇」していきます。冷たいジュースが室温でぬるくなっていく現象も、熱いお風呂が冷める現象と、数式の上ではまったく同じ仕組みで説明されます。

## 9. 数式の完全な導出

4章で示した $T(t) = T_{\text{env}} + (T_0-T_{\text{env}})e^{-kt}$ という解を、微分方程式 $\dfrac{dT}{dt} = -k(T-T_{\text{env}})$ から、一切の飛躍なく導出します。

### ステップ1: 変数を分離する

この微分方程式は「変数分離形」と呼ばれる形をしており、$T$ に関する部分と $t$ に関する部分を、両辺に分けて整理できます。

$$\frac{dT}{T - T_{\text{env}}} = -k\, dt$$

### ステップ2: 両辺を積分する

両辺をそれぞれ積分します。左辺は $T-T_{\text{env}}$ を変数と見た対数関数の積分、右辺は定数の積分です。

$$\int \frac{dT}{T-T_{\text{env}}} = \int -k\, dt$$

$$\ln|T - T_{\text{env}}| = -kt + C$$

（$C$ は積分定数）

### ステップ3: 対数を外し、指数関数の形にする

両辺を $e$ の指数として整理します。

$$|T - T_{\text{env}}| = e^{-kt+C} = e^{C}\cdot e^{-kt}$$

$e^C$ は単なる正の定数なので、これを新しい定数 $A$（$A=\pm e^C$、絶対値を外した符号込みの定数）と置き直すと、

$$T - T_{\text{env}} = A\, e^{-kt}$$

$$T(t) = T_{\text{env}} + A\, e^{-kt}$$

### ステップ4: 初期条件を使って定数 $A$ を決定する

時刻 $t=0$ のとき、お湯の温度は初期温度 $T_0$ です。この条件をステップ3の式に代入します。

$$T(0) = T_{\text{env}} + A\, e^{0} = T_{\text{env}} + A$$

これが $T_0$ に等しいので、

$$T_0 = T_{\text{env}} + A \implies A = T_0 - T_{\text{env}}$$

### ステップ5: 定数を代入し、最終的な解を得る

ステップ4で求めた $A$ をステップ3の式に代入すると、

$$T(t) = T_{\text{env}} + (T_0 - T_{\text{env}})\, e^{-kt}$$

これが4章で示した式そのものです。

### 検算: 元の微分方程式を満たすか確認する

導いた解を実際に微分し、元の方程式に戻るか確かめます。

$$\frac{dT}{dt} = (T_0-T_{\text{env}}) \times (-k)\, e^{-kt} = -k\bigl[(T_0-T_{\text{env}})e^{-kt}\bigr] = -k(T-T_{\text{env}})$$

（最後の等号は、ステップ5の式から $(T_0-T_{\text{env}})e^{-kt} = T-T_{\text{env}}$ であることを使いました。）確かに元の微分方程式 $\dfrac{dT}{dt}=-k(T-T_{\text{env}})$ と完全に一致しており、導出した解が正しいことが確認できました。
