## 1. 素朴な疑問

雨ざらしにした自転車や、湿った場所に放置した工具は、いつの間にか赤茶色にさびてしまいます。同じ金属でも、ステンレスやアルミはあまりさびないのに、鉄はなぜこんなにさびやすいのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「水に濡れると鉄そのものが変質する」説</li>
    <li><strong>直感2：</strong>「空気に触れているだけで自然に劣化していく（経年劣化）」説</li>
    <li><strong>直感3：</strong>「鉄に混じった不純物が原因」説</li>
  </ul>
</div>

実際には、さびは単なる「劣化」ではなく、鉄・水・酸素の3つが揃ったときに進行する、明確な化学反応（電気化学反応）です。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    さびは、鉄が水と空気中の酸素と結びついてできる「鉄の化合物」です。
    鉄は電子（マイナスの電気を持つ粒）を手放しやすい性質があり、その電子を酸素が奪っていくことでさびが進みます。
    水がないと電子をやり取りする通り道ができないため、乾燥した場所では鉄はほとんどさびません。
  </p>
</div>

## 4. わかりやすく厳密な答え

鉄がさびる反応は、電池と同じ仕組みの「酸化還元反応」です。金属表面の異なる場所が、電子を失う側（アノード）と電子を受け取る側（カソード）に分かれ、間を満たす水の膜が電気を通す仲立ち（電解質）として働きます。

<div class="math-proof-box">
<div class="proof-header">鉄のさびを引き起こす2つの半反応</div>
<div class="proof-body">

**アノード反応（鉄が電子を失う）：**
$$\text{Fe} \longrightarrow \text{Fe}^{2+} + 2e^-$$

**カソード反応（酸素が電子を受け取る）：**
$$\text{O}_2 + 2\text{H}_2\text{O} + 4e^- \longrightarrow 4\text{OH}^-$$

生じた $\text{Fe}^{2+}$ と $\text{OH}^-$ が結びつき水酸化鉄(II)となり、さらに空気中の酸素によって酸化されることで、
最終的に赤茶色の水和酸化鉄（さび、$\text{Fe}_2\text{O}_3\cdot x\text{H}_2\text{O}$）が生成する。

</div>
</div>

ここで重要なのは、この反応が起こるには**水**と**酸素**の両方が同時に必要だということです。水は電子を運ぶための電解質の役割を果たし、酸素は鉄から奪った電子の最終的な受け取り手になります。乾燥した環境や、酸素が遮断された環境（水中深くの酸素の少ない場所や、油を塗って密閉した状態）では、この反応がうまく進まないため、鉄は驚くほどさびにくくなります。

## 5. 数値シミュレーション

湿度条件を変えたときに、さびの進行がどう変わるかをシミュレーションしました。

![湿度条件によるさびの進行速度の違いを示すグラフ](/assets/simulations/rust_progression.png)
*図1: 乾燥した空気中ではさびがほとんど進まず、湿った空気・塩分を含む湿った空気の順に急速に進行する*

グラフは、鉄の表面のうちさびに覆われた割合が時間とともにどう増えていくかを表しています。乾燥した空気（灰色）では、時間が経ってもほとんど数値が変化しません。これは4章で説明した通り、電解質として働く水がほとんど存在しないため、電子のやり取り（酸化還元反応）が進みにくいからです。一方、湿った空気（青）では時間とともに着実にさびが進行し、さらに塩分を含む湿った空気、たとえば海の近くの環境（赤）では、さらに速く進行しています。これは塩化物イオンなどのイオンが水の電解質としての働き（電気の通しやすさ）を高め、反応を加速させるためです。船の金属部分や海沿いの建造物が特にさびやすいのは、この効果が理由です。

```python
import numpy as np

def rust_progress(t, k):
    return 100 * (1 - np.exp(-k * t))

t = np.linspace(0, 30, 300)  # 日数
dry = rust_progress(t, k=0.01)        # 乾燥した空気
humid = rust_progress(t, k=0.15)      # 湿った空気
saltwater = rust_progress(t, k=0.35)  # 塩分を含む湿った空気
```

## 7. よくある発想は何が間違っていたのか

<div class="callout callout-intuition">
  <div class="callout-title">3大直感を検証する</div>
  <ul>
    <li><strong>「水に濡れると鉄そのものが変質する」説の誤り：</strong>水だけでは鉄はさびません。密閉容器に鉄と、酸素を完全に除いた水だけを入れておくと、鉄はほとんどさびないことが実験で確認できます。反応には水に加えて酸素が不可欠です。</li>
    <li><strong>「空気に触れているだけで自然に劣化する」説の誤り：</strong>乾燥した空気中に置かれた鉄は、たとえ長期間酸素に触れていても、さびの進行は極めて遅くなります。図1のグラフが示す通り、乾燥条件では他の条件と比べてさびがほとんど進みません。酸素だけでなく水（電解質）が同時に必要です。</li>
    <li><strong>「不純物が原因」説の誤り：</strong>純度の高い鉄でも、水と酸素が揃えば同じようにさびます。不純物（他の金属との接触など）はさびの速さに影響を与えることはありますが、さびが起こる根本原因ではありません。</li>
  </ul>
</div>

## 8. さらなる疑問

**Q. ステンレスはなぜさびにくいのですか？**
ステンレスは鉄にクロムを混ぜた合金です。クロムが空気中の酸素と反応して、表面にごく薄く緻密な酸化クロムの膜（不動態皮膜）を作り、これが内部の鉄を水や酸素から物理的に遮断するバリアとして働きます。この膜は傷がついても酸素があればすぐに再生するため、ステンレスは高いさび止め効果を保ち続けます。

**Q. 亜鉛メッキ（トタン）が鉄をさびから守るのはなぜですか？**
亜鉛は鉄よりも電子を手放しやすい（酸化されやすい）金属です。鉄の表面を亜鉛で覆うと、水と酸素が来たときに鉄よりも先に亜鉛が「身代わり」になって酸化されるため、内部の鉄が保護されます。これは「犠牲陽極」と呼ばれる考え方で、船の外壁や橋の鉄骨などにも実際に応用されています。

**Q. 火星の表面が赤いのも、鉄のさびと関係あるのですか？**
はい、火星表面の赤い色は、太古の火星に存在した水や大気中の酸素によって、地表の鉄分が酸化されてできた酸化鉄によるものだと考えられています。地球の鉄がさびるのと基本的に同じ化学反応が、はるか昔の火星でも起きていたと考えられており、火星が「赤い惑星」と呼ばれる理由になっています。

## 9. 数式の完全な導出

4章で示した2つの半反応が「なぜ自然に進行するのか」を、熱力学の観点から定量的に導出します。使うのは、電気化学における2つの基本的な関係式です。

### ステップ1: 標準電極電位を確認する

酸化還元反応の起こりやすさは、「標準電極電位」という数値で比較できます。これは各半反応が還元反応（電子を受け取る方向）として進んだときの、電気的な起こりやすさを表す基準値です。

- $\text{Fe}^{2+} + 2e^- \to \text{Fe}$：$E^\circ = -0.44\,\text{V}$
- $\text{O}_2 + 2\text{H}_2\text{O} + 4e^- \to 4\text{OH}^-$：$E^\circ = +0.40\,\text{V}$

### ステップ2: 電池全体の起電力を計算する

鉄がさびる反応では、鉄が電子を失う側（酸化＝アノード）、酸素が電子を受け取る側（還元＝カソード）として働きます。電池全体の起電力（セル電位）は、次の式で計算されます。

$$E^\circ_{\text{cell}} = E^\circ_{\text{cathode}} - E^\circ_{\text{anode}}$$

ここに数値を代入すると、

$$E^\circ_{\text{cell}} = 0.40 - (-0.44) = 0.84\,\text{V}$$

$E^\circ_{\text{cell}}$ が正の値であることは、この反応が電池として自発的に電気を生み出せる、つまり自発的に進行する反応であることを意味します。

### ステップ3: ギブズ自由エネルギー変化を計算する

化学反応が自発的に進むかどうかを判定する量が、ギブズ自由エネルギー変化 $\Delta G^\circ$ です。$\Delta G^\circ < 0$ であれば、その反応は熱力学的に自発的に進行します。$\Delta G^\circ$ とセル電位の関係は、

$$\Delta G^\circ = -nFE^\circ_{\text{cell}}$$

という式で表されます。ここで $n$ は反応でやり取りされる電子の数、$F$ はファラデー定数（$F \approx 96{,}485\,\text{C/mol}$、電子1モルが運ぶ電気量）です。

4章の反応式を電子の数がそろうように書き直すと（鉄の反応を2倍して酸素の反応と電子数を4個に揃える）、$n=4$ となります。これらの値を代入すると、

$$\Delta G^\circ = -4 \times 96{,}485 \times 0.84 \approx -324{,}300\,\text{J/mol} = -324.3\,\text{kJ/mol}$$

### 結論

$\Delta G^\circ$ が大きく負の値になったことから、鉄と水と酸素からさびが生成する反応は、熱力学的に非常に強く自発的な反応であることが定量的に確認できました。これは「鉄がさびるのは、たまたま・偶然そうなる」のではなく、エネルギー的にはっきりと有利な方向に反応が進んでいることを意味します。

ただし、この計算が教えてくれるのはあくまで「反応が起こりうるか（熱力学）」であり、「どれだけ速く起こるか（反応速度、キネティクス）」は別の問題です。$\Delta G^\circ$ は湿度に関係なく常に負ですが、実際の進行速度が図1のように湿度で大きく変わるのは、水という電解質がなければ電子とイオンの移動経路が確保できず、反応が事実上ほとんど進まないためです。熱力学が「進む方向」を決め、反応速度論が「進む速さ」を決める、という2つの視点の違いが、ここに現れています。
