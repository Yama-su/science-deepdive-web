## 1. 素朴な疑問

雨上がりの空に、赤から紫まで色の帯が弧を描く虹が現れます。太陽の光そのものはほぼ白色に見えるのに、なぜ虹はあれほどはっきりと色が分かれて見えるのでしょうか。

実際には、1粒1粒の雨粒はただの透明な水の球です。虹の正体は、無数の水滴による「光の屈折と反射」が組み合わさって生まれる光学現象です。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    太陽の光が水滴に入るとき、光の進む向きが少し曲がります（屈折）。
    水滴の中で1回跳ね返り（反射）、外に出るときにもう一度曲がって、私たちの目に届きます。
    色によって曲がる角度がほんの少しだけ違うため、色ごとに別々の方向へ光が飛んでいき、結果として色の帯に分かれて見えるのです。
  </p>

## 4. わかりやすく厳密な答え

光が水滴に入るときの曲がり方は「スネルの法則」で決まります。入射角を $\theta_i$、水中での屈折角を $\theta_r$、水の屈折率を $n$ とすると、

$$\sin\theta_i = n \sin\theta_r$$

という関係が成り立ちます。虹を作る光は、①水滴に入るときに屈折、②水滴の裏側で反射、③水滴から出るときにもう一度屈折、という3段階の変化を経ます。この3段階すべてを合計した「進行方向の曲がり具合（偏角）」$D$ は、次の式で表せます。

<div class="math-proof-box">
<div class="proof-header">水滴を通過する光の偏角</div>
<div class="proof-body">

$$D = 180^\circ + 2\theta_i - 4\theta_r$$

ここで重要なのは、屈折率 $n$ は光の色（波長）によってわずかに異なるという事実（分散）である。
水の屈折率は、赤色光で $n_{\text{red}} \approx 1.331$、紫色光で $n_{\text{violet}} \approx 1.344$ とわずかに違う。
この違いが $\theta_r$ の値を色ごとにずらし、結果として偏角 $D$ も色によって微妙に異なる値になる。

</div>
</div>

さらに重要な事実があります。入射角 $\theta_i$ を少しずつ変えていくと、偏角 $D$ はある入射角で最小値をとります。この最小偏角付近では、様々な入射角から来た光がほぼ同じ方向に集中して出ていくため、その角度方向だけ特に光が強く（明るく）見えます。これが虹が「特定の角度に輝く弧」として見える理由です。この最小偏角となる正確な角度の計算は、9章で微分を使って完全に導出します。

## 5. 数値シミュレーション

入射角 $\theta_i$ を0°から90°まで変化させたときの偏角 $D$ を、赤色光と紫色光それぞれについて計算しました。

![入射角と偏角の関係を示すグラフ、赤色光と紫色光で最小偏角の位置が異なる](/assets/simulations/rainbow_deviation.png)
*図1: 赤色光（赤線）と紫色光（紫線）で、偏角が最小になる入射角・角度がわずかにずれている*

グラフの縦軸は水滴を通過した光がどれだけ方向を変えたかを表す偏角で、横軸は光が水滴に入射する角度です。どちらの色の曲線も、ある入射角でU字型の底（最小値）を持っていることに注目してください。赤色光の最小偏角は約137.6°、紫色光の最小偏角は約139.5°で、観測者から見た「太陽と反対方向の点（対日点）からの見かけの角度」に直すと、赤は約42.4°、紫は約40.5°になります。この約2°弱の差が、実際の空に見える虹の帯の幅に対応しています。赤色が虹の外側（角度が大きい側）、紫色が内側（角度が小さい側）に見えるのは、この計算結果とちょうど一致します。

```python
import numpy as np

def deviation_deg(theta_i, n):
    theta_r = np.arcsin(np.sin(theta_i) / n)
    D = np.pi + 2 * theta_i - 4 * theta_r
    return np.degrees(D)

theta_i = np.linspace(0.1, 89.9, 2000) * np.pi / 180
D_red = deviation_deg(theta_i, n=1.331)
D_violet = deviation_deg(theta_i, n=1.344)
```

## 8. さらなる疑問

**Q. 虹はなぜ円弧（アーチ）状に見えるのですか？**
「太陽と反対側の点（対日点）から見て約42°ずれた方向」という条件を満たす水滴は、観測者を頂点とした円錐の側面上に無数に存在します。この円錐と、観測者の視野（地面より上の空間）が交わる部分が円弧として見えるため、虹はアーチ状になります。理論上、上空から見下ろせば虹が完全な円として見えることもあります。

**Q. 二重の虹（副虹）はどうしてできるのですか？**
主虹は水滴内部で1回反射した光ですが、水滴内部で2回反射する光の経路も存在します。この経路からは、主虹よりも外側の約51°の角度に、主虹より暗く、色の並びが逆転した「副虹」が現れます。2回反射する分だけ光がより多く分散して失われるため、副虹は主虹より暗く見えます。

**Q. 虹に近づいたり、虹の下をくぐったりできないのはなぜですか？**
虹は特定の場所にある物体ではなく、「観測者・太陽・水滴」の間の角度関係だけで決まる、観測者ごとに異なる個人的な光学現象だからです。あなたが一歩前に進めば、それまで虹を作っていた水滴群との角度関係が変わり、代わりに少し先にある別の水滴群が新たに条件を満たして虹を作ります。つまり虹は常に観測者から一定の角度を保ちながら「逃げ続ける」ため、決して追いついて下をくぐることはできません。

## 9. 数式の完全な導出

4章で示した偏角の式 $D = 180^\circ + 2\theta_i - 4\theta_r$ がどこから来るのか、そしてこの式が最小値をとる入射角を、微分を使って一切の飛躍なく導出します。

### ステップ1: 偏角の式を組み立てる

光が水滴を通過する間に受ける「進行方向の曲がり」を、3つの段階に分けて数えます。

- **入射時の屈折：** 進行方向が $(\theta_i - \theta_r)$ だけ曲がる
- **内部での反射：** 進行方向が $(180^\circ - 2\theta_r)$ だけ曲がる（鏡面反射の幾何学的性質）
- **出射時の屈折：** 対称性により、入射時と同じく $(\theta_i - \theta_r)$ だけ曲がる

これらの曲がりをすべて合計すると、

$$D = (\theta_i - \theta_r) + (180^\circ - 2\theta_r) + (\theta_i - \theta_r) = 180^\circ + 2\theta_i - 4\theta_r$$

これが4章で使った式です。

### ステップ2: $\theta_r$ を $\theta_i$ の関数として表す

スネルの法則 $\sin\theta_i = n\sin\theta_r$ を $\theta_r$ について解くと、

$$\theta_r = \arcsin\left(\frac{\sin\theta_i}{n}\right)$$

これをステップ1の式に代入すれば、$D$ は $\theta_i$（と定数 $n$）だけの関数になります。

### ステップ3: $D$ を $\theta_i$ で微分する

$D$ が最小になる点では、傾き（微分係数）がゼロになります。合成関数の微分（連鎖律）を使うと、

$$\frac{dD}{d\theta_i} = 2 - 4 \cdot \frac{d}{d\theta_i}\arcsin\left(\frac{\sin\theta_i}{n}\right) = 2 - \frac{4\cos\theta_i / n}{\sqrt{1 - \sin^2\theta_i / n^2}}$$

### ステップ4: 微分がゼロになる条件を解く

$\dfrac{dD}{d\theta_i} = 0$ とおくと、

$$2 = \frac{4\cos\theta_i/n}{\sqrt{1-\sin^2\theta_i/n^2}}$$

両辺を整理し、$\sqrt{\ } $ を払うために両辺を2乗すると、

$$1 - \frac{\sin^2\theta_i}{n^2} = \frac{4\cos^2\theta_i}{n^2}$$

両辺に $n^2$ を掛けます。

$$n^2 - \sin^2\theta_i = 4\cos^2\theta_i$$

$\cos^2\theta_i = 1-\sin^2\theta_i$ を代入すると、

$$n^2 - \sin^2\theta_i = 4(1-\sin^2\theta_i) = 4 - 4\sin^2\theta_i$$

$\sin^2\theta_i$ の項を左辺に集めます。

$$n^2 + 3\sin^2\theta_i = 4$$

$$\sin^2\theta_i = \frac{4-n^2}{3}$$

$$\theta_i = \arcsin\sqrt{\frac{4-n^2}{3}}$$

### ステップ5: 実際の数値を代入する

赤色光（$n=1.331$）の場合、

$$\sin^2\theta_i = \frac{4 - 1.331^2}{3} = \frac{4-1.7716}{3} \approx 0.7428 \implies \theta_i \approx 59.53^\circ$$

このとき $\theta_r = \arcsin(\sin 59.53^\circ / 1.331) \approx 40.4^\circ$ となり、ステップ1の式に代入すると、

$$D_{\min} = 180 + 2(59.53) - 4(40.4) \approx 137.6^\circ$$

観測者が実際に見上げる角度（対日点からの角度）はこの補角 $180^\circ - D_{\min}$ なので、

$$180^\circ - 137.6^\circ \approx 42.4^\circ$$

紫色光（$n=1.344$）についても同じ手順を繰り返すと、最小偏角に対応する観測角は約 $40.5^\circ$ となります。

### 結論

こうして、微分によって「最小偏角」という特別な条件を導入するだけで、日常でよく言われる「虹は約42°の方向に見える」という数値が、スネルの法則という一つの物理法則から一切の仮定の追加なしに、正確に導き出されました。赤と紫の約2°の角度差こそが、私たちが目にする虹の色の帯の正体です。
