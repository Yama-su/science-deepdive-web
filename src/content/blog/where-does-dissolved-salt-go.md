## 1. 素朴な疑問

コップの水に塩や砂糖を入れてかき混ぜると、しばらくして粒が見えなくなります。溶けてなくなったように見えるこの物質は、一体どこへ行ってしまったのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「溶けると物質そのものが消えてなくなる」説</li>
    <li><strong>直感2：</strong>「溶けると新しい別の物質（化学反応の生成物）に変わる」説</li>
    <li><strong>直感3：</strong>「粒がとても小さくすりつぶされて、見えなくなっているだけで、成分自体は変わらずコップの底に沈んでいるはず」説</li>
  </ul>
</div>

実際には、塩や砂糖の粒は消えたわけでも化学変化したわけでもなく、分子やイオンという極めて小さな単位にまでバラバラになり、水全体に均一に散らばっているだけです。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    塩や砂糖の結晶は、実は目に見えないくらい小さな粒（イオンや分子）が、規則正しく積み重なってできています。
    水に入れると、水の分子がこの小さな粒の1つ1つを取り囲み、引き離していきます。
    バラバラになった塩や砂糖の粒は、コップの水全体に均等に散らばって存在し続けているので、消えてなくなったわけではないのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

物質が水に溶けるかどうかは、熱力学的な「自由エネルギー変化」によって決まります。

<div class="math-proof-box">
<div class="proof-header">溶解を決める自由エネルギー</div>
<div class="proof-body">

溶解が自発的に進むかどうかは、ギブズ自由エネルギー変化 $\Delta G$ の符号で決まる。

$$\Delta G = \Delta H - T\Delta S$$

塩の場合、結晶格子を壊すのにエネルギーが必要な一方、生じたイオンが水分子と結びつく（水和）ことで
エネルギーが放出され、$\Delta H$ はこれらが打ち消しあってほぼゼロか、わずかに正または負になる。

しかし、$\Delta S$（エントロピー変化）は、溶解によってほぼ確実に大きく増加する。
これは「混合のエントロピー」と呼ばれ、次の式で表される（導出は9章で行う）。

$$\Delta S_{\text{mix}} = -R(x_1\ln x_1 + x_2\ln x_2)$$

（$x_1, x_2$ はそれぞれの物質のモル分率）

</div>
</div>

塩のように、結晶を壊すのに必要なエネルギー（格子エネルギー）と、水和で放出されるエネルギーがほぼ釣り合っている物質では、$\Delta H$ はほぼゼロに近くなります。しかし、混合によって $\Delta S$（乱雑さ）は必ず大きく増加するため、$-T\Delta S$ の項が大きな負の値になり、全体として $\Delta G<0$（自発的に進む）となります。つまり塩や砂糖が水に溶けるのは、主に「混ざることでエントロピーが増える」という、熱力学第二法則に基づく自然な傾向によって駆動されているのです。

グラフはどの点でも0より大きい値（エントロピーの増加）を示しており、これは2つの物質がどんな割合で混ざり合っても、混合そのものが必ずエントロピーを増加させることを意味しています。また、曲線は両端（純物質、モル分率0か1）でゼロになり、ちょうど50:50で混ざったときに最大値を取る、山型の形をしています。塩や砂糖が水に溶けていく過程は、このエントロピー増加という「自然に散らばろうとする」統計力学的な傾向に、常に後押しされています。

```python
import numpy as np

R = 8.314  # J/(mol*K)

x1 = 0.3  # 溶質のモル分率(例)
x2 = 1 - x1

delta_S_mix = -R * (x1 * np.log(x1) + x2 * np.log(x2))
# x1, x2がどんな値でも(0と1の間なら)、delta_S_mixは必ず正になる
```

## 8. さらなる疑問

**Q. すべての物質が水に無限に溶けるわけではないのはなぜですか？**
物質にはそれぞれ「溶解度」という限界があります。ある濃度を超えると、それ以上の溶質を加えても水和しきれず、結晶として析出したままになります。これは4章の $\Delta G$ の式において、濃度が上がるにつれて溶液側のエントロピー的な有利さが徐々に小さくなり、ある濃度で $\Delta G=0$（平衡状態）に達するためです。

**Q. 油が水に溶けないのはなぜですか？**
油（無極性分子）は水分子と有効に水和できず、$\Delta H$ が大きく正（不利）になります。さらに、油分子が水の水素結合ネットワークを乱すことで、水分子側のエントロピーがかえって減少してしまう「疎水効果」という現象も起こります。混合のエントロピー自体は常に正の駆動力を持ちますが、油と水の場合はこれらの不利な効果がそれを大きく上回るため、全体として $\Delta G>0$ となり、溶解が進みません。

**Q. 温度が高いお湯の方が、物質がよく溶けるのはなぜですか？**
4章の式 $\Delta G=\Delta H-T\Delta S$ を見ると、多くの物質でエントロピー項の寄与は温度 $T$ に比例して大きくなります。$\Delta S>0$（多くの溶解で成り立つ）である限り、温度が上がるほど $-T\Delta S$ の項がより負に大きくなり、$\Delta G$ がより負（溶解しやすい）方向に傾きます。これが、お湯の方が物質を溶かしやすいことが多い理由です。

## 9. 数式の完全な導出

4章で使った混合のエントロピーの式 $\Delta S_{\text{mix}} = -R(x_1\ln x_1+x_2\ln x_2)$ を、統計力学のボルツマンの原理から、一切の飛躍なく導出します。

### ステップ1: ボルツマンのエントロピーの定義を確認する

統計力学において、エントロピー $S$ は、ある巨視的な状態を実現する微視的な配置の場合の数 $W$ を使って、

$$S = k_B \ln W$$

（$k_B$: ボルツマン定数）と定義されます。

### ステップ2: 分離した状態と混合した状態の、それぞれの場合の数を考える

$N_1$ 個の粒子1（溶質）と $N_2$ 個の粒子2（溶媒）が、合計 $N=N_1+N_2$ 個の格子点（配置できる場所）に並ぶ状況を考えます。

分離している状態（それぞれが別々の場所に固まっている）では、配置の場合の数は実質的に1通り（$W_{\text{separated}}=1$）とみなせます。

混合した状態では、$N$ 個の場所から、粒子1が入る $N_1$ 個の場所を自由に選ぶ組み合わせの数だけ配置のパターンが存在します。これは組み合わせの数（二項係数）で、

$$W_{\text{mixed}} = \binom{N}{N_1} = \frac{N!}{N_1!\,N_2!}$$

### ステップ3: エントロピー変化を計算する

$$\Delta S_{\text{mix}} = S_{\text{mixed}} - S_{\text{separated}} = k_B\ln W_{\text{mixed}} - k_B\ln 1 = k_B\ln\frac{N!}{N_1!N_2!}$$

### ステップ4: スターリングの近似を使って、階乗を扱いやすい形にする

$N$ が非常に大きいとき、$\ln N! \approx N\ln N - N$ という近似（スターリングの近似）が使えます。これを適用すると、

$$\ln\frac{N!}{N_1!N_2!} = \ln N! - \ln N_1! - \ln N_2!$$

$$\approx (N\ln N-N) - (N_1\ln N_1-N_1) - (N_2\ln N_2-N_2)$$

$N=N_1+N_2$ なので、$-N+N_1+N_2=0$ となり、この部分は消えます。

$$= N\ln N - N_1\ln N_1 - N_2\ln N_2$$

### ステップ5: モル分率を使って整理する

$N\ln N = (N_1+N_2)\ln N$ と書き直し、$N_1 = x_1 N$、$N_2=x_2 N$（$x_1, x_2$ はモル分率、$x_1+x_2=1$）を使うと、

$$N\ln N - N_1\ln N_1 - N_2\ln N_2 = -N_1\ln\frac{N_1}{N} - N_2\ln\frac{N_2}{N} = -N_1\ln x_1 - N_2\ln x_2$$

$N_1=x_1N$、$N_2=x_2N$ を代入すると、

$$= -N(x_1\ln x_1 + x_2\ln x_2)$$

### ステップ6: ボルツマン定数を、気体定数に変換する

$$\Delta S_{\text{mix}} = k_B\times\bigl[-N(x_1\ln x_1+x_2\ln x_2)\bigr] = -Nk_B(x_1\ln x_1+x_2\ln x_2)$$

$N$ をアボガドロ数分（$1\,\text{mol}$）とすると、$N_A k_B = R$（気体定数）という関係があるため、1molあたりのエントロピー変化として、

$$\Delta S_{\text{mix}} = -R(x_1\ln x_1+x_2\ln x_2)$$

### 結論

これが4章で使った式です。この導出でわかる本質は、「混合するとエントロピーが増える」という現象が、単なる経験則ではなく、「粒子を並べる組み合わせのパターンが、分離しているときより混ざっているときの方が、圧倒的に多くなる」という、純粋に数学的な組み合わせの理由から生まれているという点です。塩や砂糖が水に溶けて二度と自然に元の結晶へ戻らないのも、混ざった状態を実現する配置のパターンが、分離した状態に比べて天文学的に多いためなのです。
