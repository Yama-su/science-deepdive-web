## 1. 素朴な疑問

1kgのボールと10kgの鉄球を、同じ高さから同時に手を離したら、どちらが先に地面に着くでしょうか。「重い方が勢いよく落ちそう」と感じるのが自然な直感です。

## 4. わかりやすく厳密な答え

物体には2つの異なる性質があります。1つは重力によって「引っ張られる強さ」（重力質量）、もう1つは力に対して「動きにくさ」（慣性質量）です。ニュートンの運動方程式と万有引力の法則を組み合わせると、この2つがきれいに打ち消し合うことがわかります。

<div class="math-proof-box">
<div class="proof-header">定理：真空中での落下加速度は質量によらない</div>
<div class="proof-body">

ニュートンの運動方程式は $F = ma$（$m$: 慣性質量、$a$: 加速度）。
一方、地球からの万有引力は $F = \dfrac{GMm}{r^2}$（$G$: 万有引力定数、$M$: 地球の質量、$m$: 物体の重力質量、$r$: 地球中心からの距離）。

この2つの $F$ が等しいとおくと、

$$ma = \frac{GMm}{r^2}$$

両辺の $m$（質量）が打ち消し合い、

$$a = \frac{GM}{r^2}$$

となる。加速度 $a$ の式に物体自身の質量 $m$ が一切残らないため、落下加速度は物体の質量によらず一定である。

</div>
</div>

これが、質量の異なる物体でも真空中では同じ加速度（地表付近では約 $9.8\,\text{m/s}^2$）で落下する理由です。日常で「重い方が速く落ちる」ように見えるのは、空気抵抗という別の力が働いているためであり、重力そのものの性質ではありません。

## 5. 数値シミュレーション

真空中（左）と空気中（右）で、物体の落下速度が時間とともにどう変化するかをシミュレーションしました。

![真空中では質量によらず同じ速度、空気中では軽い物体が遅くなる比較グラフ](/assets/simulations/free_fall_comparison.png)
*図1: 左は真空中の理想的なケース、右は空気抵抗がある現実的なケース*

左のグラフでは、1kgの物体（青い実線）と1000kgの物体（オレンジの点線）の速度変化がぴったり重なっており、質量によって落下速度が変わらないことを表しています。右のグラフは、密度が高くて空気抵抗の影響を受けにくい「ハンマー」と、軽くて表面積が大きく空気抵抗の影響を強く受ける「羽根」を比較したものです。ハンマーはほぼ真空中と同じように加速し続けるのに対し、羽根は空気抵抗によって早い段階で速度の増加が頭打ちになり（終端速度に達し）、明らかに遅く落ちます。この違いを生んでいるのは質量そのものではなく、物体の形状や密度によって空気抵抗の効き方が変わることです。実際に1971年のアポロ15号では、空気のない月面でハンマーと羽根を同時に落とす実験が行われ、両者が同時に着地する様子が撮影されています。

```python
import numpy as np

g = 9.8
t = np.linspace(0, 2, 200)

# 真空中: 質量によらず同じ
v_vacuum = g * t

# 空気中: 終端速度に応じて頭打ちになる
def velocity_with_drag(t, terminal_v):
    tau = terminal_v / g
    return terminal_v * (1 - np.exp(-t / tau))
```

## 8. さらなる疑問

**Q. 「重力質量」と「慣性質量」が本当に等しいことは、どうやって確かめられているのですか？**
これは「等価原理」と呼ばれ、アインシュタインの一般相対性理論の出発点にもなった重要な原理です。エトヴェシュの実験や、近年では人工衛星を使った「MICROSCOPE」ミッションなどにより、10兆分の1という極めて高い精度で両者が等しいことが実験的に確認されています。

**Q. 空気抵抗がある場合、落下速度はどこまでも増加し続けるのですか？**
いいえ、空気抵抗力は速度が増すほど大きくなるため、いずれ重力と釣り合って加速度がゼロになる速度に達します。これを「終端速度」と呼び、図1右図のグラフで速度の増加が頭打ちになっている部分がこれに当たります。人間がスカイダイビングをすると、姿勢にもよりますが終端速度はおよそ秒速50m前後になります。

**Q. 月面や真空チャンバー以外で、身近に真空落下に近い現象を観察する方法はありますか？**
密閉した長い透明の筒（ニュートン管）の中の空気を真空ポンプで抜き、羽根とコインを同時に落とす実験が理科教育でよく行われます。空気があるときは大きな差がついていたのに、真空にした途端に両者がぴったり同時に落ちる様子を目で確認できます。

## 9. 数式の完全な導出

4章では「$F=ma$」と「$F=GMm/r^2$」という2つの式を等号で結んで質量を消去しましたが、なぜこの2つの式の $F$ を同じものとして扱ってよいのか、根本から確認します。

### ステップ1: 運動方程式が意味すること

ニュートンの運動の第2法則は、物体に働く力の合計 $F$ と、その結果生じる加速度 $a$ の関係を、

$$F = ma$$

と定めています。ここでの $m$ は「同じ力を受けたときに、どれだけ動きにくいか」を表す量で、これを**慣性質量**と呼びます。慣性質量が大きいほど、同じ力を受けても加速度は小さくなります。

### ステップ2: 万有引力の法則が意味すること

一方、ニュートンの万有引力の法則は、地球（質量 $M$）が物体（質量 $m$）を引く力の大きさを、

$$F = \frac{GMm}{r^2}$$

と定めています。ここでの $m$ は「どれだけ強く重力に引かれるか」を表す量で、これを**重力質量**と呼びます。重力質量が大きいほど、同じ距離でもより強く引かれます。

### ステップ3: 「慣性質量」と「重力質量」は、実は同じ数値であるという実験事実

論理的には、慣性質量（動きにくさ）と重力質量（引かれやすさ）は、まったく別の性質として定義されており、両者が等しい必然性は理論だけからは出てきません。しかし、ガリレオの実験に始まり、現代の高精度実験に至るまで、あらゆる測定でこの2つの質量は極めて高い精度で一致することが確認されています。この経験的な事実（等価原理）を認めることで、初めてステップ1とステップ2の $m$ を同じ記号として扱ってよいことになります。

### ステップ4: 2つの式を結びつけ、質量を消去する

物体が落下しているとき、物体に働く力はこの重力だけだとします。ステップ1の $F$ とステップ2の $F$ は同じ力を指しているので、

$$ma = \frac{GMm}{r^2}$$

という等式が成り立ちます。等価原理（ステップ3）により、左辺の慣性質量 $m$ と右辺の重力質量 $m$ は同じ数値なので、両辺を $m$ で割ることができます（$m \neq 0$ を仮定）。

$$a = \frac{GM}{r^2}$$

### 結論

導かれた式の右辺には、地球の質量 $M$ と地球中心からの距離 $r$ しか残っておらず、**物体自身の質量 $m$ がどこにも現れません**。これは、地表からの高さがほぼ同じであれば（$r$がほぼ一定なら）、どんな質量の物体を落としても、加速度 $a$ はまったく同じ値（地表付近で約 $9.8\,\text{m/s}^2$）になることを意味します。この「$m$が消える」という一見単純な代数計算の中に、「重いものも軽いものも同じ速さで落ちる」という、直感に反する物理法則の核心が詰まっているのです。
