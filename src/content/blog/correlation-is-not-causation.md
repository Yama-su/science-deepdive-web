## 1. 素朴な疑問

統計を取ると、「アイスクリームの売上が多い日ほど、水難事故の件数も多い」という、はっきりした相関関係が見つかります。では、アイスクリームの販売を規制すれば、水難事故を減らすことができるのでしょうか。

## 2. よくある発想

<div class="callout callout-intuition">
  <div class="callout-title">よくある3大直感</div>
  <ul>
    <li><strong>直感1：</strong>「強い相関関係があれば、基本的にそれは因果関係を意味する」説</li>
    <li><strong>直感2：</strong>「相関係数が高ければ高いほど、片方がもう片方の直接的な原因である可能性が高い」説</li>
    <li><strong>直感3：</strong>「相関がまったくないなら、両者の間に因果関係も絶対に存在しない」説</li>
  </ul>
</div>

実際には、相関関係は単に「2つの量が一緒に変化する傾向がある」という統計的な事実を示すだけであり、片方がもう片方の原因であることを保証するものではありません。アイスクリームと水難事故の例では、両者に直接の因果関係はなく、「気温」という共通の原因（交絡変数）が、両方に影響を与えているだけです。

## 3. わかりやすい模範的答え

<div class="callout callout-kids">
  <div class="callout-title">子どもへの伝え方（要点）</div>
  <p>
    アイスクリームがよく売れるのも、水難事故が増えるのも、本当の原因は「気温が高いこと」です。
    暑い日は、アイスクリームを買う人も増えますし、泳ぎに行く人も増えて水難事故のリスクも上がります。
    アイスクリームと水難事故は、直接は無関係で、ただ同じ「暑さ」という原因を共有しているだけなのです。
  </p>
</div>

## 4. わかりやすく厳密な答え

なぜ直接の因果関係がないのに、統計的な相関が生まれてしまうのか、数式を使って確認してみましょう。

<div class="math-proof-box">
<div class="proof-header">交絡変数がつくる見せかけの相関</div>
<div class="proof-body">

アイスクリーム売上 $X$ と水難事故数 $Y$ が、どちらも共通の変数（気温）$Z$ にのみ依存し、
互いには直接影響しないモデルを考える。

$$X = aZ + \varepsilon_X, \qquad Y = bZ + \varepsilon_Y$$

（$a, b$ は正の定数、$\varepsilon_X, \varepsilon_Y$ は$Z$や互いに無関係な、独立なノイズ項）

このとき、$X$ と $Y$ の共分散は、

$$\text{Cov}(X,Y) = ab\cdot\text{Var}(Z)$$

となる（導出は9章で行う）。$a, b$ が正で、$Z$ に変動（$\text{Var}(Z)>0$）がある限り、
$X$ と $Y$ の間には、直接の因果関係が一切なくても、正の相関が必ず生まれる。

</div>
</div>

つまり、たとえ $X$（アイスクリーム売上）を人為的に操作しても、それによって $Y$（水難事故数）が変化することはありません（$X$ から $Y$ への矢印は式のどこにも存在しないからです）。それにもかかわらず、両者は共通の原因 $Z$（気温）を通じて統計的に連動して見えるため、相関係数を計算すると、あたかも関係があるかのような正の値が出てしまうのです。

## 5. 数値シミュレーション

気温だけに依存する仮想的なアイスクリーム売上データと水難事故データを生成し、両者の関係をプロットしました。

![気温を色で示した、アイスクリーム売上と水難事故数の散布図](/assets/simulations/correlation_confounder_demo.png)
*図1: アイスクリーム売上と水難事故数には強い相関(r≈0.81)が見られるが、両者を直接結びつけるコードは一切書かれていない*

このシミュレーションでは、「アイスクリーム売上が水難事故を引き起こす」というルールはプログラムのどこにも書かれていません。実際に計算に使われているのは、「気温が高いほどアイスクリームがよく売れる」「気温が高いほど水難事故が増える」という、2つの独立したルールだけです。それにもかかわらず、生成されたデータをプロットすると、右上がりのはっきりとした相関（相関係数はおよそ0.81）が現れています。点の色は気温を表しており、暖色（高温）の点が右上に、寒色（低温）の点が左下に集まっていることから、この相関が気温という共通の要因によって生み出されていることが視覚的にも確認できます。

```python
import numpy as np

rng = np.random.default_rng(11)
temperature = rng.uniform(0, 35, 200)

ice_cream_sales = 20 * temperature + rng.normal(0, 100, 200)
drowning_incidents = 0.8 * temperature + rng.normal(0, 4, 200)
# ice_cream_sales -> drowning_incidents の関係は一切コードにない
correlation = np.corrcoef(ice_cream_sales, drowning_incidents)[0, 1]  # 約0.81
```

## 7. よくある発想は何が間違っていたのか

<div class="callout callout-intuition">
  <div class="callout-title">3大直感を検証する</div>
  <ul>
    <li><strong>「強い相関＝因果関係」説の誤り：</strong>4章・5章で見た通り、直接の因果関係が一切なくても、共通の原因（交絡変数）を通じて強い相関が生まれることが、数式でもシミュレーションでも明確に示されました。相関の強さは、因果関係の有無を保証しません。</li>
    <li><strong>「相関係数が高いほど因果の可能性が高い」説の誤り：</strong>相関係数の大きさは、あくまで2つの変数が「一緒に動く度合い」を表す統計量であり、その背後にあるメカニズム（直接の因果か、交絡変数を介した間接的な関係か）については何も語りません。今回の例では相関係数0.81という、決して低くない値が、完全に交絡変数だけから生まれています。</li>
    <li><strong>「相関がなければ因果関係もない」説の誤り：</strong>これも一般には誤りです。例えば、原因変数が結果変数に対して「U字型」の非線形な影響を与える場合（少なすぎても多すぎても悪影響、適量が最良、といった関係）、直線的な相関係数はほぼゼロになることがありますが、それでも明確な因果関係は存在します。相関係数（特にピアソンの積率相関係数）は、主に「直線的な関係」しか検出できないという限界があります。</li>
  </ul>
</div>

## 8. さらなる疑問

**Q. 因果関係があるかどうかは、どうすれば確かめられますか？**
最も信頼できる方法は「ランダム化比較実験」です。対象をランダムに2つのグループに分け、一方にだけ介入（例：ある薬を投与する）を行い、もう一方には行わず、結果の違いを比較します。ランダムに分けることで、年齢や体質などのあらゆる交絡変数の影響が両グループで平均的に打ち消し合うため、観測された差を介入の因果効果として、より正当に解釈できます。

**Q. 「シンプソンのパラドックス」とは何ですか？**
全体のデータでは相関があるように見えても、データをグループ（例えば年齢層など）に分けて見ると、相関の向きが逆転してしまう現象です。これも交絡変数が引き起こす統計的なわなの一種で、データをどの単位（全体か、グループ別か）で分析するかによって、まったく違う結論が導かれてしまう危険性を示す、有名な例です。

**Q. 因果関係がなくても、相関関係だけで予測に役立てることはできますか？**
はい、目的によっては有用です。例えば、傘の売上とタクシーの需要には相関がありますが（両方とも「雨」が原因）、傘の売上データからタクシー会社が需要を予測して車両を配置する、といった実用的な使い方は可能です。ここで重要なのは、「傘を規制すればタクシー需要が減る」という誤った介入の結論を導かないことです。予測（相関の利用）と介入（因果関係の利用）は、目的に応じて明確に区別する必要があります。

## 9. 数式の完全な導出

4章で示した $\text{Cov}(X,Y)=ab\cdot\text{Var}(Z)$ という関係式を、共分散の定義から一切の飛躍なく導出します。

### ステップ1: 共分散の定義を確認する

2つの確率変数 $X, Y$ の共分散は、

$$\text{Cov}(X,Y) = E\bigl[(X-E[X])(Y-E[Y])\bigr]$$

と定義されます（$E[\ ]$ は期待値を表す）。

### ステップ2: $X, Y$ の期待値を計算する

$X=aZ+\varepsilon_X$、$Y=bZ+\varepsilon_Y$ で、$\varepsilon_X, \varepsilon_Y$ の期待値は0（ノイズは平均的には偏りがないと仮定）とすると、

$$E[X] = aE[Z], \qquad E[Y] = bE[Z]$$

### ステップ3: 偏差を計算する

$$X - E[X] = a(Z-E[Z]) + \varepsilon_X, \qquad Y-E[Y] = b(Z-E[Z])+\varepsilon_Y$$

### ステップ4: 共分散の定義に代入し、展開する

$$\text{Cov}(X,Y) = E\Bigl[\bigl(a(Z-E[Z])+\varepsilon_X\bigr)\bigl(b(Z-E[Z])+\varepsilon_Y\bigr)\Bigr]$$

これを展開すると、4つの項が現れます。

$$= ab\,E\bigl[(Z-E[Z])^2\bigr] + a\,E\bigl[(Z-E[Z])\varepsilon_Y\bigr] + b\,E\bigl[(Z-E[Z])\varepsilon_X\bigr] + E[\varepsilon_X\varepsilon_Y]$$

### ステップ5: 独立性を使って、不要な項を消去する

$\varepsilon_X, \varepsilon_Y$ は、$Z$ とも互いとも無関係な（独立な）ノイズだと仮定しているため、独立な確率変数どうしの共分散は0になるという性質（$E[(Z-E[Z])\varepsilon_Y]=0$ など）により、2番目・3番目・4番目の項はすべてゼロになります。

$$\text{Cov}(X,Y) = ab\,E\bigl[(Z-E[Z])^2\bigr]$$

### ステップ6: 分散の定義を使って整理する

$E[(Z-E[Z])^2]$ は、まさに分散 $\text{Var}(Z)$ の定義そのものです。したがって、

$$\text{Cov}(X,Y) = ab\cdot\text{Var}(Z)$$

### 結論

これが4章で使った関係式です。この導出から、$X$ と $Y$ の間に共分散（ひいては相関）が生まれる原因が、$X$ と $Y$ を直接結びつける項ではなく、両者が共有する変動要因 $Z$ の分散 $\text{Var}(Z)$ から、$a$ と $b$ という2つの「感度」の積を通じて、間接的に生み出されていることが明確にわかります。$a=0$（気温がアイスクリーム売上に影響しない）または $b=0$（気温が水難事故数に影響しない）であれば、共分散は正確にゼロになり、相関も一切生まれません。相関の正体は、しばしば「直接のつながり」ではなく、「共通の親を持つ、いとこ同士の関係」なのです。
